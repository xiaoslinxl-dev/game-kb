# 疯狂水世界 核心循环

《疯狂水世界》的核心体验驱动力来自于“拾荒生产 - 基地扩建 - 英雄推关 - 联盟协作/城战”的多重闭环循环。

## 1. 核心闭环结构

```text
  [海面拾荒/深海潜水/钓鱼捕捞]
            │
            ▼ (收集木板、金属、塑料、绳索、蓝图)
  [加工生产与居民订单] ───(升级/委任)───► [扩建海上城邦/人口突破]
            │                                     │
            ▼ (获得经验、金币、加速沙漏)            ▼ (解锁高阶工厂/英雄委派)
  [卡牌推关与挂机放置] ◄───(提升战力/装备)─── [英雄抽卡与升星养成]
            │
            ▼ (获取徽章/藏品/万能碎片/水母币/竞猜积分)
  [联盟商船协作 / 巅峰擂台赛 / 大地图城战争夺]
```

## 2. 三层循环详解

### 第一层：经营与生存闭环（短周期：分钟/小时级）

1. **资源收集与自动化进阶**：
   - 基础建材按收集优先级排序：**木板 ＞ 金属 ＞ 塑料 ＞ 绳索**，是建造与扩建木筏的绝对刚需。
   - **资源收集器**：开荒初期优先升至 3 级，免费解锁自动打捞功能，极大降低手动拾取频率。
   - **拾荒船**：建造后即可出海拾荒；升至 2 级后解锁自动拾荒，航行速度同时提升 20%。拾荒过程中需警惕深海鲨鱼袭击，若被鲨鱼撞击累计达 3 次则拾荒任务失败。
   - **钓鱼台**：提供生鱼基础原料，达到指定等级后解锁自动钓鱼，钓获新鱼种可累积鱼类图鉴积分并解锁永久属性加成。
   - **深海潜水**：23 级解锁潜水船坞，深入沉船与沉没遗迹打捞高阶蓝图、稀有金属与藏品。
2. **加工制造与基础循环构建**：
   - 14 级前优先解锁工作台、切鱼厂与种植农场，建立**“收集－生产－储备”**的完整基础循环。
   - 通关第 100 关后解锁**“海上田园”**系统，在木筏上开垦农田种植农作物，为居民订单与对外贸易储备粮食原料。
3. **订单交付与人口增长**：
   - 完成居民委托订单与贸易港口货轮订单，获取玩家经验（EXP）、金币与加速沙漏。
   - 建设民居增加基地人口，建造发电站、医院、礼堂等设施打破人口上限门槛，满足新建筑与工厂升级的人口红线。

### 第二层：养成与推关闭环（中周期：天级）

1. **战力养成与词条精炼**：
   - 消耗金币与经验提升英雄等级（最高为玩家等级 5 倍）。
   - 英雄升至 **3 星** 解锁核心质变技能；利用【洗刷锁】在超凡装备和海兽洗炼时锁定核心词条（如闪避率、攻速、暴击），搭配蓝色装备可实现 3 秒快速锻造。
   - 配置专属武器与战术核芯（如 1.1.6 新增的【登峰】核芯）。
2. **放置推关（PVE）与关键突破**：
   - 通关主线关卡，开局第一天强烈建议将关卡推至 **70 关以上**，通关 70 关后挂机收益正式掉落建造极缺的核心物资**“蓝图”**。
   - 关卡支持自动连续推关与 10 秒后跳过战斗，挂机持续产出金币、经验、蓝图与随机徽章。
   - **800 关“双博士”卡点**：开荒期关键分水岭，敌方双博士高爆发压制，通常需切换闪避增强阵或初始能量阵，通过 [机器屠夫](/entities/units/ji-qi-tu-fu.md) 的上下位飞钩机制精准拉取并后置保护主 C 兰博多次凹关突破。
3. **资源反哺**：
   - 关卡产出的蓝图与沙漏反哺基地工厂升级，提高生产效率与高阶建材产出。

### 第三层：社交与对抗闭环（长周期：周/赛季级）

1. **联盟协作与商船出海**：
   - 16 级加入联盟，享受全员生产互助与轻质钢每日互刷功勋；参与限时 3 天的【联盟商船】订单交付，赚取水母币兑换黄金徽章自选、超凡藏品万能碎片与超凡技能书。
2. **大地图沙盘与硅矿争夺（GvG）**：
   - 参与大地图要塞与城池争夺、硅矿采集（每日限 30 次抢占上限），赛季结算按盟主战利品分配机制发放赛季币与稀有奖励。
3. **天梯竞技与巅峰对决（PVP）**：
   - 跨服竞技场每日天梯排行结算；参与【巅峰擂台赛】（利维坦前 128 名淘汰赛），全员参与多阶段赛事竞猜赚取永久竞猜积分，构建竞技与泛娱乐并重的高粘性社区。
