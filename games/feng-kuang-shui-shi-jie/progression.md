# 疯狂水世界 数值与养成系统

《疯狂水世界》的战力成长体系分为“基础属性（等级/升星/技能）”与“额外加成（装备/精炼词条/徽章/海兽/藏品/核芯）”两大核心支柱，并提供了无损重生的养成容错机制。

## 1. 玩家等级与建筑门槛

- **等级上限与内容扩展**：S7 赛季玩家等级上限提升至 **100 级**，主线闯关新增至 **4300 关**，日常试炼副本扩展至 **140 关**。
- **玩家经验（EXP）获取途径**：主线/日常/支线任务 > 居民委托订单 > 建筑建造升级 > 关卡推图（30 EXP/关）> 贸易货轮。
- **人口红线机制**：高级建筑建造与升级必须达到对应的人口需求。人口通过民居（小型/中型/大型）增加，人口上限需通过发电站、医院、礼堂、水上乐园等特殊建筑打破。
- **70 关分水岭**：开局第一天须尽快将关卡推至 70 层以上，通关 70 层后挂机奖励开始掉落极缺的“蓝图”；通关 100 关后解锁“海上田园”农田种植系统。

## 2. 英雄养成体系与梯队定位

### 升星与技能解禁
- **等级上限**：英雄等级上限为当前玩家等级的 5 倍，升级消耗英雄经验与金币。
- **升星（质变节点）**：英雄达到 **3 星** 才能解锁核心的第 4 技能。1 技能（主动大招）与 4 技能（被动核心机制）共同决定英雄强度的质变。
- **万能碎片分配**：推荐分配顺序为：[大嘴山姆](/entities/units/da-zui-shan-mu.md)（懂王拉到3星解锁全屏嘲讽） → [兰博](/entities/units/lan-bo.md)（拉到3星开启攻速红温爆发） → [巫师老侃](/entities/units/wu-shi-lao-kan.md)（拉到3星提供全队护盾增伤） → [过江龙](/entities/units/guo-jiang-long.md)（狂浪节战士拉高爆发）。
- **无损重生**：游戏提供无损重生功能，英雄重生 100% 返还升级经验与进阶金币。但**传说万能碎片与传说技能书为不可返还稀缺资源**，必须慎重投给核心 T0 英雄。

## 3. 装备、精炼与徽章系统

- **装备三部位**：
  - **枪械**：能量输出英雄优先打造（如兰博）。
  - **兵刃**：物理输出与刺客英雄优先打造（如千代、铁腿红魔、过江龙）。
  - **防具**：前排主坦英雄优先打造（如大嘴山姆、探案双子星）。
  - **快速锻造技巧**：搭配蓝色基础装备可实现 3 秒快速锻造，加速积累高阶装备。
- **超凡装备精炼（Affixes Refining）与洗刷锁**：
  - 精炼属性分为基础属性与额外属性，关键洗练等级节点为 **65 级**（解锁第 1 词条）与 **100 级**（解锁第 2 词条）。
  - **洗刷锁机制**：1.1.6 版本引入关键道具【洗刷锁】，在超凡装备和海兽洗炼时可锁定极品词条（最多锁定 2 条），锁定后洗炼该词条保持不变，大幅降低洗废成本。
  - **主 C 词条优先级**：攻速（兰博需控在 1.0-1.2 区间）、暴击率、暴击伤害、攻击力百分比、抗性穿透。
  - **主坦词条优先级**：闪避率（大嘴山姆需堆至 75% 闪避阈值）、伤害减免、生命值百分比、暴击抗性、控制抗性。
  - **辅助/控场词条优先级**：攻速（加速技能循环）、技能强度、生命减伤、控制抗性。
- **高级属性【控制抗性】**：1.1.6 版本新增高级属性，使英雄受到的控制效果持续时间减少（涵盖击飞、晕眩、冰冻、石化、御风吹离战场）。
- **徽章品质**：沉木 < 黑铁 < 青铜 < 白银 < 黄金。黑铁及以上品质自带随机词条，无法洗练；巅峰擂台赛商店与联盟商船产出黄金徽章自选。

## 4. 战术核芯、海兽培育与藏品套装

- **战术核芯（Core）**：
  - **登峰**：1.1.6 新增核芯。造成或承受伤害时获得一层【不屈】（提升护甲与抗性并可叠加持续至战斗结束）；叠加至满层时立即净化控制效果，并获得【登峰】状态（造成伤害大幅提升），是持久战与残局翻盘神级核芯。
- **海兽系统（23级解锁培育室）**：
  - [鳌蟹](/entities/units/ao-xie.md)：超凡防御海兽（全队双抗、护盾吸收、霸体免控）。
  - **铁甲人鱼**：S5 赛季登场的限定超凡海兽，提供反伤与减益净化。
  - [海豚](/entities/units/hai-tun.md)：传说万金油海兽（为 3 名友军持续回血与高额减伤）。
  - **鲨鱼/章鱼**：针对敌方回血阵容与提供群体眩晕。
- **藏品套装（Relic Sets）**：
  - **天下布武**：1.1.6 新增超凡文物藏品套装，提供高额进攻穿透与伤害加成。
  - **美式工具箱**：1.1.6 新增超凡文物藏品套装，提供基地建造加速与综合防御加成。
  - **奇珍异兽博物馆**：美人鱼联动限定橙藏品套装，提供全队攻击与生命大幅加成。
  - **荣耀之巅**：赛季商店兑换的红藏品套装，提供 PVP 城战伤害与减伤增益。
- **外观全员属性加成**：
  - 特殊皮肤附带全员战力加成，如大嘴山姆皮肤【超能吵骑士】提供全体英雄生命、攻击、技能强度 +2%。
