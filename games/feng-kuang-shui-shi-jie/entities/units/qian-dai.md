# 千代 (Qian Dai)

## 1. 角色定位与特性

千代是《疯狂水世界》S2 赛季实装的超凡品质刺客/输出英雄，其上线彻底打破了传统靠前排硬抗的 PVP 环境。

- **核心机制**：
  - **精准锁头**：优先以敌方攻击力最高的英雄（通常为敌方主 C 兰博）为攻击目标。
  - **减伤与隐匿**：四技能解锁后自带 40% 高额伤害减免与隐匿机制，能在切入后排后大幅提高生存几率。
  - **能量极速启动**：配合“20 初始能量徽章”开局可迅速释放大规模式爆发技能。

## 2. 装备与词条精练

- **词条优先级**：**暴击率** > **暴击伤害** > **攻击力** > **穿透**。
  - *机制原因*：千代定位为纯粹的高爆发切后排刺客，追求开局直接秒杀敌方主力输出。
- **推荐装备**：
  - **枪械**：能量炮 / 脉冲步枪
  - **防具**：抗压头盔
  - **兵刃**：等离子大剑

## 3. 培养与获取建议

- **获取途径**：S2 赛季限定活动与招募大奖。
- **阵容搭配**：S2 赛季后可进入一队替代传统辅助，或在二队中作为第一核心主 C 带领第二输出梯队。
