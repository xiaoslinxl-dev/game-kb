# 疯狂水世界 核心循环

《疯狂水世界》构建了从海上打捞求生到联盟城战协作的完整玩法流转闭环：

## 1. 基础资源收集与建设起步

玩家在生存初期以“拾荒奠基”为核心，需要从打捞海上漂浮物开始，将塑料、金属等文明残骸转化为初始资源，完成从求生到建设的第一步。[@来源](sources/evidence.md#ev-658b0425f6a038047c7a0adf7d84d1de)

## 2. 联盟组织运作与资源互助

避难所建立后，玩家融入联盟体系展开协作：

- **领导选举**：开服第三天22点，联盟贡献榜前五自动成为盟主及副盟主；盟主若三日未上线将被接替。[@来源](sources/evidence.md#ev-fd6273194431acbce581a7ba32adbd86)
- **募兵与集结**：成员在推荐城市募兵可获得额外功勋，盟主及副盟主可负责宣战和集结。[@来源](sources/evidence.md#ev-fd6273194431acbce581a7ba32adbd86)
- **材料互助**：每日可发起20次材料求助，帮助盟友可获得功勋；求助请求超时24小时自动取消。[@来源](sources/evidence.md#ev-fd6273194431acbce581a7ba32adbd86)

## 3. 功勋产出与成长资源兑换

联盟玩法产出的功勋直接反馈至角色养成：

- **功勋获取途径**：主要通过攻城战、联盟募兵和互助获得。[@来源](sources/evidence.md#ev-7c5211ad16e38b9600cf636eeba609a3)
- **商店核心兑换**：功勋优先兑换联盟商店中的传说英雄万能碎片（每周限10次）与传说技能书（每周限20次）。[@来源](sources/evidence.md#ev-7c5211ad16e38b9600cf636eeba609a3)
- **建筑皮肤兑换**：底部两款建筑皮肤需90万/150万功勋兑换，微氪玩家亦可选择直接购买（材料厂皮肤18元、货轮港口30元）。[@来源](sources/evidence.md#ev-7c5211ad16e38b9600cf636eeba609a3)

## 4. 舰队作战状态与战斗限制

在城战对抗与出征作战中，舰队生存状态直接影响战斗结果：当舰队耐久归零时，该0耐久舰队将受到极强战力惩罚，其伤害、护盾与治疗均削减100%（-100%）。[@来源](sources/evidence.md#ev-a959e5a4c93acf6eb34c842c6e7998c4)
