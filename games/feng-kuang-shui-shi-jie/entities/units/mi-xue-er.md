# 蜜雪儿 (Mi Xue Er)

## 1. 角色定位与特性

蜜雪儿是《疯狂水世界》新手阶段免费赠送的“五巨头”之一，也是全期泛用性极强、性价比极高的万金油控场回能型辅助（T0/T1 辅助）。凭借群体冰冻控制与全队回能光环，被玩家公认为队伍的“战术发动机”与推图控场保障。

- **阵营与职能**：能量辅助 / 群体控场兼全队回能。
- **获取难度**：极低（新手剧情赠送，招募掉率高，不依赖高星即可上阵发挥关键控场作用）。

## 2. 技能机制详解

1. **核心大招 ——“极寒冰城”**：
   - 随机冻结敌方 3 名目标，冰冻持续 2.4 秒。该技能具备极高战术价值，可强行打断敌方前排技能施放与后排大招爆发，为我方主 C [兰博](/entities/units/lan-bo.md) 争取宝贵的攻速叠加时间。
2. **被动技能 1 ——“霜冻迟缓”**：
   - 受到普攻或技能伤害时，使攻击者移动速度与攻击速度下降 20%，持续 3 秒。
3. **被动技能 2 ——“急冻庇护”**：
   - 战斗开始时为自身及相邻队友施加寒冰护盾，护盾吸收相当于自身最大生命值 18% 的伤害。
4. **质变核心技能（4技能）——“能量潮汐”**：
   - 大招施放后，为全队英雄恢复 16 点怒气/能量值，使全队技能循环冷却空档缩短约 25%，极大加速了主坦 [大嘴山姆](/entities/units/da-zui-shan-mu.md) 与辅助 [巫师老侃](/entities/units/wu-shi-lao-kan.md) 的大招释放。

## 3. 阵容搭配与站位

- **万能国家队配置**：
  - [大嘴山姆](/entities/units/da-zui-shan-mu.md)（主坦） + [兰博](/entities/units/lan-bo.md)（主C） + [巫师老侃](/entities/units/wu-shi-lao-kan.md)（增伤） + **蜜雪儿**（控场/回能） + [机器屠夫](/entities/units/ji-qi-tu-fu.md) / [千代](/entities/units/qian-dai.md) / [李忠诚]
- **站位要点**：通常放置在后排安全位（如最下方第二排或第一排），避免第一轮被敌方单体爆发集火，确保稳定放出第一次冰冻与回能。
- **阵法选择**：攻速增强阵（提升施法频率）或 能量增强阵。

## 4. 词条与养成要领

- **升星策略**：平民玩家 1 星即可上场充当控场挂件，万能碎片应优先留给兰博与懂王，蜜雪儿依靠日常抽卡自然升星。
- **词条优先级**：攻击速度 > 生命值 > 伤害减免 > 效果抵抗。无需堆叠攻击输出词条，专精攻速以加快控场大招循环。
