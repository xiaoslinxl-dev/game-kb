# 核心循环

《斗罗大陆：魂师对决》的核心玩法闭环建立在“**资源获取/体力消耗 → 魂兽猎杀/副本挑战 → 魂环/魂骨/魂核获取 → 魂师阵容强化 → 悬赏榜/PVP竞技突破**”之路上。

```text
  [日常/体力消耗]
   ├── 猎魂森林 / 落日森林 ──► 获取高年份魂环 / 魂核 / 魂涡
   ├── 世界探索 / 斗罗之路 ──► 获取养成材料与突破道具
   └── 悬赏 / 极限战境   ──► 获取高阶魂骨与代币
            │
            ▼
  [魂师与阵容养成]
   ├── 魂环搭配（一至四魂环/双系/神化）
   ├── 魂骨/外附燃骨/魂核/本源强化
   └── 阵容编队（强攻+敏攻+控制+防辅协同）
            │
            ▼
  [高阶玩法与商业化变现]
   ├── 跨服PVP（全民对决/巅峰联赛）
   ├── 宗门战（嘉陵关/大陆征伐）
   └── 限时诏令卡池（SP+ / SP 魂师抽卡与源魂养成）
```

## 1. 玩法闭环详解

### (1) 资源积累阶段
- **体力管理**：每天通过自然恢复、购买体力（月卡/尊享特权）及托管系统获取体力。
- **日常副本**：
  - **猎魂森林 / 落日森林**：猎杀魂兽获取魂环（万年、十万年、神息魂环）以及魂核/魂涡材料。
  - **世界探索与剧情**：通过地图解密、一键开宝箱与主线推进获取基础材料。

### (2) 阵容深度养成
- **魂师培育**：升星、觉醒、魂力链接（8位支柱魂师共享等级与基础实力）。
- **装备与魂环系统**：为强攻、敏攻、控制、防辅不同职业的魂师装配专属魂骨（1-6星）、外附燃骨、魂核（第一至第三魂核）。

### (3) 验证与竞技
- **PVE 短图与长图**：
  - **短图**（如剧情、极限战境）：强调快速拉条与高爆发一波流。
  - **长图**（如世界悬赏、外传）：强调多回合增伤、叠加阵法/缘劫与可持续输出。
- **PVP 竞技与宗门**：
  - **全民对决与巅峰联赛**：公平或练度竞技，争夺限定封号与荣誉。
  - **嘉陵关/大陆征伐**：宗门集体攻城略地，验证整体团战深度。
