# 商业化体系

《斗罗大陆：魂师对决》采用了成熟的数值卡牌商业化模式，通过“**卡池抽卡保底 + 限定诏令/通行证 + 分层礼包 + 皮肤与外观**”实现高 ARPPU 变现。

## 1. 抽卡卡池（Gacha）

- **常规与自选卡池**：提供 SSR 自选与日常武魂觉醒。
- **SP / SP+ 限时主题卡池**：
  - 新魂师上线（如 `SP+ 太初食神·奥斯卡`、`SP+ 极致剑道·尘心`、`SP+ 十方琉璃·宁荣荣`、`SP+ 千面幻影·妖魅`）时开启专属卡池。
  - **保底机制**：通常设 50-60 抽保底或硬保底次数，首次或联动期间有保底抽数减免（如《仙逆》联动 SP 王林首次保底减少 50 抽）。
  - **源魂与神魂**：抽到本体后，后续需要继续抽取源魂/源心以解锁更高的神力阶级与技能分支。

## 2. 运营通行证与诏令（Pass System）

- **普通通行证 / 豪华通行证**：
  - **诏令系列**：如“神塔诏令”、“潮夏龙鸣诏令”、“光黯诏令”、“灵眸诏令”、“灵眸好礼”。
  - 售价通常为 68元 - 128元 不等，购买豪华版可获取专属代币、自选 SP 源魂、双神降临觉醒券、星源赐福礼、钻石及限定皮肤。

## 3. 礼包与订阅体系（Bundles & Subscription）

- **月卡与特权**：
  - **小月卡（30元）/ 大月卡（68元）/ 豪华月卡**：购买立即获得钻石，31天内每日返还钻石与体力，并提供专属特权加速与高额资源加成。
  - **堂主/VIP 特权**：充值累计达到一定档位（如 360 元）解锁多倍体力购买额度与托管快捷领取特权。
- **每日/每周分层礼包**：
  - 每日 1-18 元小额礼包（属性香肠、体力、觉醒券）。
  - 周常高阶礼包（燃骨灰烬、魂涡·锥、万能碎片）。

## 4. 特殊活动商业化

- **斗魂奇石 / 赐福商城 / 星月奇运 / 神界秘藏**：采用“先抽后付”或幸运升档扭蛋/三层星盘转盘抽奖机制，吸引中高氪玩家获取顶阶凶兽魂环、蜕变源骨、简·幻金骨等稀有资源。
