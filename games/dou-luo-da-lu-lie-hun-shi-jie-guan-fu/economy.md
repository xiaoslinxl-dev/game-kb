# 经济系统

《斗罗大陆：猎魂世界》的经济系统围绕“体力（精神/行动力）”这一核心产出控制阀展开，分为货币流、抽取道具流与材料流三大闭环。

## 1. 货币流

| 货币名称 | 主要获取途径 | 核心消耗用途 |
| :--- | :--- | :--- |
| **海神币** | 删档测试返还 / 充值 | 直购付费礼包、通行证、代扣真实货币 |
| **钻石** | 主线成就/地图宝箱/日常活跃/充值 | 购买武魂觉醒券、购买体力、限时秘藏/抽奖礼盒 |
| **金魂币** | 副本掉落/任务奖励/地图搜集 | 技能升级、魂环强化、魂核强化、宗门捐赠 |
| **宗门贡献币** | 宗门任务/宗门合战/宗门争霸 | 宗门商店兑换武魂潜能材料 |
| **荣誉币** | 斗魂对决竞技 / 组队助战 | 荣誉商店兑换高阶养成资源、圣明灭生玉（70级解锁） |
| **远征兑换币** | 远征计划（单队训练+双队讨伐） | 远征商店必换外附魂骨升星材料「骨华凝晶」、魂环突破材料「古遗创世玉」 |
| **星神玉** | 限定卡池抽卡附赠 / 修罗秘藏保底 | 星神玉商城兑换十万年灵核、神赐奥义、对决魂骨 |

## 2. 核心消耗资源（体力）

- **体力回复速度**：每 1 小时自动恢复 10 点。
- **购买与补充**：月卡每日领 60 点，每日可消耗钻石购买 3 次体力。
- **消耗大户**：
  - 拟态副本（刷取武魂突破材料与经验）。
  - 猎魂魂兽（20 体力/次，产出不同年份魂环）。

## 3. 高阶材料与养成闭环

- **外附魂骨材料**：
  - **骨华凝晶**：外附魂骨升星核心材料，通过远征计划商店优先拉满兑换。
  - **年份提升材料**：对应灵瞳骨、晶心铠等基础外附魂骨与特定年份四肢星级魂骨。
- **符文进阶与突破材料**：
  - **暗金与赤金符文**：核心/四肢魂骨符文，暗金需先升至金色符文品质后方可突破，2.0 版本支持升品至赤金。
  - **玄骨珏 / 焚骨玉**：核心/四肢符文自选箱备选高阶材料。
  - **古遗神念玉 / 圣明灭生玉**：高阶魂环与魂骨强化突破材料，依开服天数分层产出。
  - **启灵破天玉 / 万能突破石**：魂骨与武魂突破关键消耗品。

## 4. 交易与回收

- 游戏为封闭式 MMORPG 经济，玩家间无公开自由交易行，主要依靠宗门拍卖行分配拍卖红利（拍卖宗门争霸产生的稀有道具，全员瓜分分红）。
- 魂核/魂骨拥有回溯与分解功能，返还大部分强化材料；2.0 版本新增魂核中枢重置功能，允许对指定武魂单独重置中枢养成。
