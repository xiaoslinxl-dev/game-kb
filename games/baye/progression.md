# 养成系统

《霸业》的养成体系包含“外围卡牌与武将深度深度养成”与“内围封地/军功爵位养成”两条并行主线。

## 1. 武将养成体系

武将是游戏的核心战斗载体，按品质分为绿、蓝、紫、橙（及神将/圣将）：

- **升级与突破**：使用经验书与突破材料提升武将等级与带兵数。
- **武将觉醒**：消耗同名卡或特殊觉醒材料，大幅提升武将四维属性（统、勇、智等可加至110-120以上），并解锁觉醒天赋与专属特效。
- **神兵与皮肤**：佩戴武将专属神兵（如青龙偃月刀、方天画戟）获得额外属性加成；使用高级皮肤（如马超“锐金戟骑”皮肤）提升全队战力与外形样式。
- **战法搭配**：每个武将可配备主战法与自选辅助战法，根据阵容需求配置输出、控制或治疗战法。

## 2. 兵种科技与培育

- **四大兵种进化**：普通士兵通过“兵种科技”进行研习，逐步从基础兵种升级至虎贲郎及高阶兵种（如陷阵营、白马义从、强弩兵、西凉铁骑等）。
- **属性加成**：兵种科技提升直接作用于全队该兵种属性（攻击、防御、暴击、抗性）。

## 3. 爵位与官职体系

- **战功与官职**：玩家在国战中击杀敌军、攻占城池或完成国家任务可累积战功。战功达标后可从最低阶（如义兵、伍长）逐步晋升至县尉、中郎将、太守、州牧乃至安汉公等高阶官职。
- **爵位俸禄与伤害压制**：
  - **俸禄收益**：官职越高，每日可领取的资源与银两俸禄越丰富。
  - **官职压制**：高级官职对低于本官职的玩家具有额外百分比伤害加成（如对低官职玩家造成额外伤害）。

## 4. 封地建设与产业系统

- **城建与产出**：主城/封地内包含集贤府、兵营、藏兵阁、农田、采石场等建筑，通过升级建筑提升基础资源（粮草、银两、木材、铁矿）的每小时产量。
- **产业占领**：在大地图上占领野外资源产业，获取额外的特产资源与加成。
