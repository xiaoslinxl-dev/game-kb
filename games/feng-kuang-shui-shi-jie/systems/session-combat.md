# 疯狂水世界 对抗与卡牌战斗系统

《疯狂水世界》的战斗系统采用 5v5 自动/半自动卡牌即时与回合对抗，强调“前排承伤 + 后排爆杀”的阵型站位与机制克制。

## 1. 阵容构成与站位机制

出战小队由 5 名英雄组成，分为前排（通常 1-2 名主/副坦）与后排（输出 C 位及辅助）：

- **阵型光环加成**：
  - **闪避增强阵**：提升全队闪避率（适合前排大嘴山姆主 T 队）。
  - **攻速增强阵**：提升全队攻击速度（适合射手/主 C 兰博队，帮助兰博快速达到 1.13 攻速门槛）。
  - **初始能量阵**：让法师/辅助英雄开局快速释放大招（如千代/老侃）。
  - **能量恢复阵**：加快大招能量循环。

## 2. 战术钩子与位移克制（以机器屠夫为例）

- **机械钩子拉人**：机器屠夫具有核心的“对位勾人”机制。在站位安排上：
  - 机器屠夫放置在上排时，优先拉取对面上排后排；放置在下排时拉下排；放置在中间时随机拉取。
  - **战术用途**：将机器屠夫放置在后排或侧翼，开局直接将对方的核心后排输出或主 T（如敌方大嘴山姆）钩至己方后排附近，配合主 C 兰博瞬间集火秒杀，破除敌方前排防线。

## 3. 海兽技能介入

战斗中可出战 1 只培育室养殖的海兽，海兽技能不占英雄行动回合：
- **鳌蟹**：为全队套盾、加双抗与免控，防秒杀能力极强。
- **海豚**：为随机 3 名英雄持续回血并赋予减伤效果，高普适性万金油。
- **鲨鱼**：对敌方造成伤害并施加禁疗/减疗，克制双奶回血队。
- **章鱼**：对敌方前中排造成眩晕控制，打断大招。

## 4. 战斗减负体验

- **10 秒跳过**：主线推关与副本战斗在开始 10 秒后均提供“跳过”按钮，无需长时间等待。
- **自动推关**：支持后台自动挂机连续推关，配合无损重生，极大降低了手动试错成本。
