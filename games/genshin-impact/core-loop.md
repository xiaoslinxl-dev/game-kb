# 原神 核心循环

《原神》的核心循环由大世界探索、元素策略战斗与队伍角色强化紧密咬合而成。在探索维度，玩家规划体力翻山越岭与横渡江河，探索提瓦特大陆，交互游荡的仙灵与奇异装置。[@证据](sources/evidence.md#ev-1cb412d926dd429c011d4ab65b0cc96f)

在战斗机制层面，世界由风、雷、水、火、冰、草、岩七大元素构成，拥有「神之眼」的角色引导元素之力投入战斗与探险，通过技能触发如水火「蒸发」、火雷「超载」、雷水「感电」等元素交互效果制胜敌人。[@证据](sources/evidence.md#ev-cb6beba73b5a954ea77623fc792cac89)

在养成与验证闭环上，玩家结识能力独特的伙伴，摸索队伍搭配，利用旅途中搜集的各类材料强化角色，进而征服提瓦特大陆上的魔物与挑战各类秘境。[@证据](sources/evidence.md#ev-5d55b71b1ce1af7e94f178655ffe8273)
