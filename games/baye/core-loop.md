# 霸业 核心循环

## 势力选择与版图扩张

在《霸业》中，玩家需要选择魏蜀吴其中一方势力，建设封地，招募三国名将，不断提升实力。本国玩家需要齐心协力，攻城掠地，不断扩大国家势力版图，从而一统三国。[@来源](sources/core-loop.md#ev-b664b5127bdaff5d9788eff01739737d)[@版本unknown]

## 棋盘连城大地图国战

国战采用创新棋盘连城大地图，具备全民攻城、突进封路、残兵撤退、密道突袭与实时战术布置，带来全新策略体验。[@来源](sources/core-loop.md#ev-727104250a6c7af004b69f00e63c6147)[@版本unknown]

## 国家建设与元宝分红

玩家攻城拔寨、扩张版图，参与国家建设和国战，即可免费瓜分海量元宝分红。[@来源](sources/core-loop.md#ev-5460dce82854e9202f3604f0dc6b7ee9)[@版本unknown]
