# 战斗系统

《霸业》结合了卡牌阵型布阵与SLG沙盘即时对演，战斗核心在于武将三维数值、兵种相克、战法协同以及阵型调度。

## 1. 兵种体系与克制关系

游戏中包含四大核心基础兵种及延伸进阶兵种：
- **步兵**：高防御、高血量，擅长前排抗伤。
- **骑兵**：高机动、高冲击，对远程式兵种具有极强突破能力。
- **弓兵**：远程输出，高爆发，但生存能力较为脆弱。
- **术士/辅助**：提供群体治疗、控制（如【反间】、默化）或增益加成。

基础克制循环通常遵循：`步兵克制弓兵`、`弓兵克制骑兵`、`骑兵克制步兵`，在国战或沙盘对决中，针对敌方部队类型合理调整兵种占比可获得额外伤害加成与减伤收益。

## 2. 武将属性与武将战法

武将拥有三大核心属性，直接决定其在战斗中的定位：
- **统（统帅）**：决定武将的带兵上限与部队基础防御能力。
- **勇（武力）**：决定武将及所带物理部队的直接攻击属性与单挑伤害。
- **智（智谋）**：决定战法/战术技能的释放效果、谋略伤害与计谋防御。

武将技能分为：
- **主将技**：武将处于主将位置时触发的专属核心技能（如马超的高爆发骑兵冲锋、姜维的四维提升与全军【反间】伤害）。
- **兵种技**：针对特定兵种（如锐金戟骑、强弩等）的伤害或属性强化。
- **辅助技/被动技**：主公可自主选择搭配的战法，赋予部队吸血、减伤、控制或免控状态。

## 3. 沙盘战斗与即时调度

- **大地图城池攻防**：战斗在沙盘城池与关隘节点展开，支持多部队批量驻守与对撞。
- **单挑与全军冲击**：部分PVE或特定对局中保留了武将武艺单挑（武力比拼与单挑加成）及随后的全军混战机制。
- **自动化与手动微调**：大地图战斗支持自动行军与挂机对撞，玩家亦可手动指派攻城队列或及时撤退补给。
