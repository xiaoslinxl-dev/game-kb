# 霸业 核心循环

在《霸业》的大地图对抗中，游戏采用创新棋盘连城大地图，战术操作包括全民攻城、突进封路、残兵撤退与密道突袭，支持实时战术布置。[@来源](sources/evidence.md#ev-727104250a6c7af004b69f00e63c6147)

在大地图扩张与收益回馈层面，玩家通过攻城拔寨、扩张版图以及参与国家建设和国战，可免费瓜分海量元宝分红。[@来源](sources/evidence.md#ev-5460dce82854e9202f3604f0dc6b7ee9)

在封地建筑升级与资源运转方面，每次建筑升级都需要一定的材料；根据2024年8月的新手攻略记载，前期若升级建筑次数较多则木头会十分缺少，在建筑升级过程中可同步去攻城做巡城任务，每次巡城都会获得一定量的资源补充。[@来源](sources/evidence.md#ev-44c02d60ff846bf837a0d8850176ec1b)

在日常政务、征战与副本养成环节，2024年7月的攻略指出政务是关键环节，每日政务次数需全部购买，以加速官邸升级、武将提升和血战沙场次数的增加；每日征战中的血战沙场次数也需购买满，以获取大量武将技能碎片和材料；演义之路中的扫荡次数也应尽量达到上限，以获取升级武将和兵种所需的材料、经验书以及升级武将技能所需的大量银币。[@来源](sources/evidence.md#ev-a9095836110f82bb7e77aa19ca4f770e)
