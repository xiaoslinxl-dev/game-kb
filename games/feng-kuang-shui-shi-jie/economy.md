# 疯狂水世界 经济系统

《疯狂水世界》的经济系统围绕“原料打捞 - 工厂加工 - 订单变现 - 商店消费 - 战力转化”建立，兼顾了模拟经营的物资流转与卡牌 RPG 的深度数值消耗。

## 1. 代币与资源分类

| 资源/代币 | 主要产出途径 | 主要消耗用途 | 紧缺度/瓶颈阶段 |
|---|---|---|---|
| **金币** | 居民订单、贸易货轮、挂机收益、日常试炼、月卡每日赠送 | 英雄升级、装备打造、建筑建造与升级 | 全时期极度紧缺的第一基础货币 |
| **钻石** | 主线任务、关卡通关、活动成就、充值内购 | 开服第 8 天兰博/老侃转盘、特权商店买加速沙漏、租用自动生产 | 前期需严格囤积（1.5万钻保底），不可滥抽基础招募池 |
| **蓝图** | 70关以上关卡挂机掉落、日常任务、居民订单、联盟商店 | 所有高级建筑与工厂的建造和升级 | 前中期极度稀缺的建造红线物资 |
| **英雄经验** | 挂机收益、经验试炼、居民订单、主线通关 | 英雄等级提升（上限为玩家等级 5 倍） | 中后期等级拉升的关键数值卡点 |
| **硅晶/硅矿** | S3 赛季大地图硅矿采集、周度加工活动 | 联盟科技研发、高阶装备精炼 | 中后期 SLG 联盟争霸核心战略资源 |
| **赛季币** | 赛季城战排名、赛季任务成就、赛季结算 | 赛季商店兑换红藏品“荣耀之巅”、海兽基因自选 | 长线跨赛季累积（结算不清空）硬通货 [1.7] |

## 2. 生产与物资加工流转链

```text
  [海面打捞/拾荒船] ──► 木材、塑料、金属 ──► [材料厂/建材厂] ──► 墙纸、零件、钢板 ──┐
                                                                                 │
  [钓鱼台/海产捕捞] ──► 生鱼 ─────────────► [切鱼厂/海产厨房] ──► 生鱼片、罐头 ─────┼─► [居民订单 & 贸易货轮] ──► 金币 + 经验 + 沙漏
                                                                                 │
  [海水提取厂] ─────► 淡水、盐 ───────────► [日用品店/选种厂] ──► 饮用水、作物 ───────┘
```

1. **上游原料层**：海面拾荒、钓鱼台捕鱼、潜水船坞打捞深海物资、海水提取淡水。
2. **中游加工层**：切鱼厂、材料厂、选种厂、建材厂生产二级半成品与高级消耗品。
3. **下游变现层**：
   - **居民订单**：提交指定组合的加工品，获取玩家经验与金币；S3 赛季起订单满意度奖励扩展至全传说英雄碎片 [1.7]。
   - **贸易港口货轮**：装载高阶成品换取大量金币、藏品宝箱与加速沙漏。

## 3. 商店交易与代币流通

- **特权商店**：消耗钻石购买 1 分钟/5 分钟加速沙漏（首日微氪 V2 玩家通过购买 2400 沙漏刷货轮订单快速升至 16 级开启联盟）。
- **联盟商店**：消耗联盟贡献币兑换传说英雄碎片（如 [小丑杰克](/entities/units/xiao-chou-jie-ke.md)）、建造蓝图与海兽培育饲料。
- **试炼商店**：通关试炼副本产出试炼币，用于兑换高阶徽章锻造石与精炼材料。
- **赛季商店**：消耗赛季币兑换红藏品与超凡海兽升星数据自选 [1.7]。
