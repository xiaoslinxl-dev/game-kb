# 千面幻影·妖魅

## 1. 角色定位与背景

「千面幻影·妖魅」是《斗罗大陆：魂师对决》于 2026 年 8 月 29 日推出的**首位 SP+ 敏攻系魂师**。在此之前，敏攻系已长达近 10 个月未推出核心新卡，全副本敏攻生态长期由联动角色 SP 王林占据主导。SP+ 妖魅的登场不仅填补了 SP+ 敏攻系的空白，更凭借多形态战术切换重塑了敏攻在长图、短图与 PVP 竞技中的核心地位。

## 2. 核心机制：幻面天成

SP+ 妖魅的核心机制为「**幻面天成**」，允许妖魅根据战局需求在 4 种不同的“身份面具”间进行形态转换：

- **A 身份（长图单体 / 持续增伤）**：
  - 携带大量单体增益与伤害放大 Buff，专精于长图悬赏与单桩 BOSS 输出，可极大提升全队总伤害上限。
- **B 身份（群体爆发 / 极限战境）**：
  - 主打群体范围伤害与爆发收割，契合短图 PVE、极限战境与快速清场副本的特殊规则。
- **C 身份（PVP 竞技 / 幻境对决）**：
  - 竞技场特化形态，具备将敌方核心目标强制拉入独立幻境进行一对一单挑的强力控场机制，有效限制敌方核心 C 位或打火拉条魂师。
- **D 身份（多功能辅助与变奏）**：
  - 提供环境适应性机制与生存/闪避加成，增强面对高压逆境时的容错率。

## 3. 阵容搭配与魂环推荐

- **长图单桩阵容**：
  - **核心组合**：SP+ 千面幻影·妖魅 + 双神·唐三（神祇第7人） + SP+ 太初食神·奥斯卡 + SP+ 月神·小舞 + SP+ 十方琉璃·宁荣荣 + 防辅/增伤魂师。
  - **战术要点**：通过太初食神的食神飨宴与月神小舞的望舒领域持续叠伤，由 A 形态妖魅在长图中打出高频巨额伤害。
- **PVP 竞技阵容**：
  - **核心组合**：SP+ 千面幻影·妖魅 + SP+ 罗刹神·比比东 + SP+ 十方琉璃·宁荣荣 + 双神·唐三 + SP+ 极致剑道·尘心。
  - **战术要点**：开局抢一速拉条控场，妖魅开启 C 身份切入敌方关键位置，配合比比东压制敌方魂力。

## 4. 商业化与养成权重

- **获取途径**：2026年8月29日开启限时武魂召谕卡池；2026年8月29日后开启的新服将在开服第 3 天内置开启专属卡池。
- **养成深度**：升星至红五星/彩星解锁源魂心技孔位，配套专属魂骨与蜕变源骨，具有极高的商业化优先级与版本 Meta 统治力。
