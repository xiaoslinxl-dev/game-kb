# 疯狂水世界 核心循环

《疯狂水世界》的核心体验驱动力来自于“拾荒生产 - 基地扩建 - 英雄推关 - 联盟协作/城战”的多重闭环循环。

## 1. 核心闭环结构

```text
  [海面拾荒/深海潜水/钓鱼]
            │
            ▼ (获取木材、金属、塑料、蓝图)
  [加工生产与居民订单] ───(升级/委托)───► [扩建海上城邦/人口突破]
            │                                     │
            ▼ (获得经验、金币、加速沙漏)            ▼ (解锁高阶建筑/英雄位)
  [卡牌推关与挂机放置] ◄───(提升战力/装备)─── [英雄抽卡与升星养成]
            │
            ▼ (获取徽章/藏品/万能碎片/水母币/竞猜积分)
  [联盟商船协作 / 巅峰擂台赛 / 大地图城战争夺]
```

## 2. 三层循环详解

### 第一层：经营与生存闭环（短周期：分钟/小时级）

1. **资源收集**：通过海面点击/自动拾荒船打捞木材、金属、塑料；在钓鱼台捕鱼；在潜水船坞搜寻高阶藏品与深海稀有物资。
2. **加工制造**：在切鱼厂制作生鱼片，在材料厂/建材厂加工墙纸、钢板、零部件等半成品与成品。
3. **订单交付与人口增长**：完成居民订单与贸易港口货轮需求，获得玩家经验（EXP）、金币与藏品材料。建设民居增加人口，建造发电站/医院等设施打破人口上限，满足新建筑与工厂升级的建造门槛。

### 第二层：养成与推关闭环（中周期：天级）

1. **战力养成**：利用产出的金币与经验提升英雄等级（玩家等级 5 倍），通过转盘/招募获取英雄碎片升星解锁 3 星质变技能，洗练超凡装备与徽章词条（利用“洗刷锁”锁定核心词条），激活专属武器与核芯（如“登峰”）。
2. **放置推关（PVE）**：通关主线关卡（70 关后解锁蓝图掉落），通关更高层级以提升挂机每小时的金币、经验与高阶徽章品质。
3. **资源反哺**：关卡挂机奖励反哺蓝图与高级材料，支撑基地进一步扩建与更高阶工厂解锁。

### 第三层：社交与对抗闭环（长周期：周/赛季级）

1. **联盟协作与商船出海**：16 级加入联盟，全员互助加速生产，参与 3 天一期的【联盟商船】出海交付货舱订单，赚取水母币兑换高阶养成资源。
2. **大地图沙盘与硅矿争夺（GvG）**：大地图要塞与城池争夺、硅矿占领（每日 30 次抢占上限控制恶意消耗），赛季结算按盟主战利品分配机制发放赛季币与限定外观。
3. **天梯竞技与巅峰对决（PVP）**：参与跨服竞技场与【巅峰擂台赛】（利维坦前 128 名淘汰赛），全员参与赛事竞猜赚取永久竞猜积分，构建长线高粘性竞技生态。
