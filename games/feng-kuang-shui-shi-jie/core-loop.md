# 疯狂水世界 核心循环

《疯狂水世界》的核心体验驱动力来自于“拾荒生存 - 基地扩建 - 英雄推关 - 极限试炼 - 联盟协作/城战 - 征服赛季”的多重闭环循环。

---

## 1. 核心闭环结构

```text
  [海面拾荒/深海潜水/钓鱼捕捞] ──(呼应现实“净滩行动”四大阵营减碳冲刺)
            │
            ▼ (收集木板、金属、塑料、绳索、蓝图)
  [加工生产与居民订单] ───(升级/委任/水姆特权/双节30%加速)───► [扩建海上城邦/人口突破]
            │                                                               │
            ▼ (获得经验、金币、加速沙漏、月爪与盲盒卡)                       ▼ (解锁高阶工厂/兵工厂/英雄委派)
  [卡牌推关、极限试炼与放置] ◄───(提升战力/核芯/阵型)────────── [英雄抽卡、翻牌池、升星与流转核芯]
            │                                                               ▲ (远征商店每周 20 枚超凡碎片)
            ▼ (获取徽章/藏品/万能碎片/水母币/竞猜积分)                              │
  [联盟商船协作 / 巅峰擂台赛 / S6+ 征服赛季「黑潮入侵」8 势力水之都 280+ 地块争霸]
```

## 2. 四层洋葱式融合驱动模型（行业深度解构）

据 2026 年 9 月行业权威复盘（Enjoy出海），《疯狂水世界》的底层成功密码在于将多重品类拆解为“层层嵌套、递进展开”的四层洋葱式架构：

```text
  ┌─────────────────────────────────────────────────────────────────────────┐
  │ 4. Light SLG & Conquest Season (16级/S6+ 征服赛季 8 势力 280+ 地块对决)   │
  │    ┌───────────────────────────────────────────────────────────────┐    │
  │    │ 3. Card Battle & Flip Pool (5v5 推关、翻牌池、极限试炼与反哺)   │    │
  │    │    ┌─────────────────────────────────────────────────────┐    │    │
  │    │    │ 2. Simulation (生产链、12元特权、水姆5折、双节30%特权)│    │    │
  │    │    │    ┌───────────────────────────────────────────┐    │    │    │
  │    │    │    │ 1. Survival (破木筏起手、捡垃圾、钓鱼、拾荒)  │    │    │    │
  │    │    │    └───────────────────────────────────────────┘    │    │    │
  │    │    └─────────────────────────────────────────────────────┘    │    │
  │    └───────────────────────────────────────────────────────────────┘    │
  └─────────────────────────────────────────────────────────────────────────┘
```

1. **第一层：Survival 负责起手（秒懂吸量）**：
   - 游戏开局脚下只有一块漂在海上的破木板，第一件事就是“捡垃圾”。捡废料、救幸存者、钓鱼、拾荒，操作极其简单直观，前 30 分钟不露任何重度 SLG 元素，让泛用户在 3 秒内建立代入感。在 9 月下旬上线的“净滩行动”中，这一动作更与“渤海、黄海、东海、南海”四大阵营打捞垃圾积累减碳值形成深度呼应。
2. **第二层：Simulation 撑住日常（经营留存与第一变现漏斗）**：
   - 玩法迅速进入“采集—建造—加工”的生产循环。随着资源种类增加、加工链拉长，玩家进入供需瓶颈，顺势打开了**12 元解锁材料自动生产**与**水姆商店会员特权（5折优惠+当周消费半价退还）**的核心变现切口。双节期间（9.23-10.6）开启的全厂生产加速 30% 特权与海獭宠物皮肤（+5%）更构成了阶段性经营狂欢。
3. **第三层：Card Battle 承接成长（双向赋能、极限试炼与新翻牌保底）**：
   - 推关、日常试炼、3天限时**「极限试炼」**、竞技场驱动英雄等级、星级、专武、阵型与战术核芯（如流转核芯、登峰核芯）养成。英雄不仅负责战斗，更拥有内城委派提速技能，形成“基地养人，人反哺效率”的良性反哺。9 月实装的“翻牌卡池”（10 抽一大奖，保底自选海兽与 300 红色超凡碎片）与远征商店每周 20 枚超凡万能碎片，构成了中长期卡牌战力进阶的主轴。
4. **第四层：Light SLG 补上社交、扩张与赛季（轻量化大世界与开荒规划）**：
   - 16 级压后开放大地图与联盟。无主城自由拆家，同盟资源点独立，以舰队耐久度替代死兵惩罚；而在 S6 及后续版本中全面升级为 **S6+ 征服赛季**，首发世界剧本「黑潮入侵」，地图沙盘地块由 97 块大幅扩展至 280+ 块，引入 8 势力争夺水之都、「黑潮」动态禁战天候与**汽油远征维修成本递增机制**，带来更严谨的 GvG 战术博弈与缓冲空间。

## 3. 三层推进循环体系

### 第一层：单局与单日微循环（短周期：分钟至小时级）

1. **海面拾荒与资源捕捞**：
   - 手动/自动打捞海面漂流的废弃箱（木板、金属、塑料、绳索）；
   - 钓鱼台捕捞海鱼制作生鱼片；派出拾荒船外海巡逻拾荒（警惕鲨鱼袭击）；
   - 23 级解锁潜水船坞，下潜深海废墟打捞高阶稀有建材与藏品宝箱；
   - **净滩行动打捞**：在基地拾取漂浮垃圾产出基础材料的同时，同步积累个人与阵营“减碳值”。
2. **基地加工与工业链转化**：
   - 工作台与材料厂将基础原材料转化为钢板、零件、绳索等半成品；
   - 委派英雄入驻指挥中心提供生产提速；
   - 51 级解锁【兵工厂】，扫荡海盗获取原料加工城市工事耗材；
   - 结合中秋国庆双节 30% 全厂提速与水姆 5 折特权，极大缩短高频订单的制造等待周期。
3. **订单交付与人口增长**：
   - 完成居民委托订单与贸易港口货轮订单，获取玩家经验（EXP）、金币与加速沙漏；
   - 结合【水姆商店会员特权】半价扫货核心建材，加速订单交付周转；
   - 建设民居增加基地人口，建造发电站、医院、礼堂、水上乐园等设施打破人口上限门槛，满足新建筑与工厂升级的人口红线。

### 第二层：养成与推关闭环（中周期：天级）

1. **英雄培养与战力跃迁**：
   - 消耗金币与经验提升英雄等级（最高为玩家等级 5 倍）；
   - 英雄升至 **3 星** 解锁核心质变技能；利用【洗刷锁】在超凡装备和海兽洗炼时锁定核心词条（如闪避率、攻速、暴击），搭配蓝色装备可实现 3 秒快速锻造；
   - 配置专属武器与战术核芯（如【登峰】核芯、【流转】核芯）；根据敌方站位配置 4 种新阵型（伤害增加/减免、控制抗性Ⅰ/Ⅱ）；
   - **远征商店超凡碎片常态化**：达到 51 级后可在远征商店消耗远征币兑换【超凡英雄万能碎片】（每周上限 20 枚），大幅缓解平民玩家只够养 1~2 个超凡英雄的严重瓶颈。
2. **放置推关（PVE）与关键突破**：
   - 通关主线关卡，开局第一天强烈建议将关卡推至 **70 关以上**，通关 70 关后挂机收益正式掉落建造极缺的核心物资**“蓝图”**；
   - 关卡支持自动连续推关与 10 秒后跳过战斗，挂机持续产出金币、经验、蓝图与随机徽章；双节期间挂机与闯关额外掉落活动道具「月爪」与盲盒卡；
   - 800 关面对“双博士”卡关点时，需适时后置 [机器屠夫](/entities/units/ji-qi-tu-fu.md) 钩走对称位关键单位打破僵局。
3. **循环挑战「极限试炼」**：
   - 周期性限时开启（每期持续 3 天，S1-S3 赛季在第 25~27 天开启，S4 赛季起在第 22~24 天以及第 46~48 天开启）；
   - 考验全卡池多队极限承伤与爆发，通关高层挑战产出大量高阶培养材料与荣誉代币。实战中针对“通关困难模式登榜”需求，平民社区提炼出以李忠诚+机修罗莉机械召唤流拆分二队承伤的闭环通关策略。

### 第三层：社交与对抗闭环（长周期：周/赛季级）

1. **联盟协作与商船出海减负**：
   - 16 级加入联盟，享受全员生产互助与轻质钢每日互刷功勋；参与限时 3 天的【联盟商船】订单交付。优化后**只要半数以上船员登船，倒计时结束即自动启航**，赚取水母币兑换黄金徽章自选、超凡藏品万能碎片与超凡技能书。
2. **S6+ 征服赛季世界剧本「黑潮入侵」（9月22日实战深化）**：
   - 从 S6 赛季起全区服正式改制为**“征服赛季”**，首发「黑潮入侵」剧本，由 4 联盟升级为 8 势力对决，争夺中心奇观“水之都”；
   - **大地图沙盘地块扩充至 280+ 块**，整点万吨货轮（2艘）、中型货轮（10艘）、小型货轮（12艘）与硅矿（高等14/中等32）成倍增加；
   - **黑潮禁战与禁铺路规则**：黑潮吞没的城市不可宣战且不可用于铺路连地，迫使联盟必须根据黑潮涨落规划进军节奏；
   - **汽油维修成本递增新机制**：舰队在外海维修耐久度所消耗的汽油随距主城距离成正比递增，促使战盟形成“攻占加油站前哨 - 建立中继站 - 集中油料推进”的严谨组织战术循环；
   - **尾刀抢城战术**：最后一击决定城池归属，联盟采取末段耐久集火与外围阻截战术确保攻城成果。
3. **巅峰擂台赛与全民竞猜**：
   - 跨服积分赛前 128 名争夺冠军，全民参与竞猜投票赚取积分，积分永久保留，在赛事商店换取登峰核芯与超凡碎片。
