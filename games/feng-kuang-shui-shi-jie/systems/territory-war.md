# 疯狂水世界 联盟领地战系统规则

《疯狂水世界》的联盟领地战以城战策略、攻防积分与舰队耐久管理为核心机制：

## 1. 城战开放时间与占领积分

- **时间规则**：城战于每日 20:00-21:00 开放，成功占领城市必须击败所有守军；海盗城市无玩家干预，进攻优先级最高。[@来源](../sources/evidence.md#ev-03f2d4922bc1113b4a2d86fb5beee6a2)
- **城市等级积分**：占领 1-6 级城市分别获得 1-6 分；占领 7-13 级城市逐级增加 5 分，可获得 10-40 分；占领 14 级城市获得 50 分；占领 15 级山景城获得 200 分。[@来源](../sources/evidence.md#ev-03f2d4922bc1113b4a2d86fb5beee6a2)

## 2. 舰队耐久与损耗惩罚

- **耐久上限与Debuff**：原皮舰队初始耐久为 2000 点；当舰队耐久低于 1500 点时触发 Debuff 状态；舰队每分钟可自动修复 400 点耐久；达到 VIP3 后可解锁自动委任功能。[@来源](../sources/evidence.md#ev-03f2d4922bc1113b4a2d86fb5beee6a2)
- **0耐久惩罚与撤回规则**：舰队耐久降至 0 时，伤害、护盾与治疗均减少 100%（-100%）；处于点火城的 0 耐久舰队允许撤回，以避免舰队被卡死。[@来源](../sources/evidence.md#ev-1acc8e485fdf9a1b8d3fb5036b8393ac)

## 3. 城战攻防实战技巧

- **偷城战术**：当目标城市守军数量低于 200 时，联盟成员可执行全员闪击战术，抢夺城市最后一击的归属权。[@来源](../sources/evidence.md#ev-34ed94cf45e08bac1c42bbf9e4a3e3ee)
- **防御协同**：当本方城市被宣战时，应优先驻守敌军主力进攻的城市；低战力玩家快速刷募兵任务，高战力玩家可消耗钻石加速守城。[@来源](../sources/evidence.md#ev-34ed94cf45e08bac1c42bbf9e4a3e3ee)

## 4. 赛季机制扩展与攻防规则

- **联盟结盟**：联盟结盟功能于 S5 赛季正式开启。[@来源](../sources/evidence.md#ev-be6ce77de799e9763b4ce63fa7982f11)
- **多宣战方城市旗帜**：在城市攻防中，如果有多个宣战方，城市左侧不显示进攻方的旗帜。[@来源](../sources/evidence.md#ev-be6ce77de799e9763b4ce63fa7982f11)
- **防务与科技调整**：S5 赛季推出新联盟科技，并对城防军与海盗进行调整。[@来源](../sources/evidence.md#ev-be6ce77de799e9763b4ce63fa7982f11)
