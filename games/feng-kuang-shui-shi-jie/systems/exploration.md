# 疯狂水世界 海域探索与资源收集

《疯狂水世界》塑造了多元化的海域探索体验，涵盖海面拾荒、深海潜水、垂钓捕捞、文物修复及应对动态天气系统。

## 1. 资源收集的三大维度

1. **海面打捞（拾荒）与资源收集器**：
   - 基础物料收集优先级：**木板 ＞ 金属 ＞ 塑料 ＞ 绳索**。
   - 玩家在主界面可手动点击海面漂流的废弃箱与物资包。
   - **资源收集器**：核心基础设备，升至 3 级后解锁自动打捞功能，极大减少前期高频点击。
   - **拾荒船**：建造后可派船出海巡逻拾荒；升级至 2 级解锁自动拾荒，航行速度同时提升 20%。拾荒过程中需要警惕鲨鱼追击，若被鲨鱼撞击累计达 3 次，该次拾荒即告失败并损失部分打捞收益。

2. **深海潜水（潜水船坞）**：
   - 23 级后解锁，玩家驾驶潜水艇深入沉没都市与沉船废墟。
   - 在有限氧气时间内搜寻高阶蓝图、藏品碎片与黄金宝箱，同时需规避深海海兽袭击。
   - 解锁“自动潜水”后，若仓库中的基础潜水材料满仓，自动潜水会自动寻找并开启深海隐藏宝箱。

3. **垂钓捕捞（钓鱼台）与鱼类图鉴**：
   - 生产生鱼片的基础来源。玩家达到指定等级后解锁自动钓鱼。
   - 通过升级鱼竿与鱼饵品质，可以捕捞稀有巨型海鱼，成功钓到新鱼种可累积鱼类图鉴积分，解锁丰厚的全队属性加成。
   - 1.1.6 版本对钓鱼图鉴进行了视觉与数值迭代（如野生胭脂鱼、刀锋鳍士图鉴升级），丰富了图鉴收藏属性加成。

## 2. 文物修复与博物馆藏品系统

- **广州海事博物馆文创扩展**：引入“古物修复”与数字考古机制，玩家在深海探险中打捞出南海沉船瓷器残片后，可在修复工坊进行拼合还原，解锁数字文创展品。
- **藏品套装与博物馆展区（28级解锁）**：
  - **天下布武**：1.1.6 新增超凡文物藏品套装，提供穿透与全队伤害加成。
  - **美式工具箱**：1.1.6 新增超凡文物藏品套装，提供建造加速与防御属性加成。
  - **奇珍异兽博物馆**：美人鱼联动限定橙藏品套装，提供攻击与生命大幅提升。
  - **荣耀之巅**：赛季商店兑换红藏品套装，提供城战攻防百分比增益。
  - 激活藏品套装可为对应职业英雄带来全额属性加成，并提升基地建造生产效率。

## 3. 动态天气与昼夜交替

- **暴风雨与巨浪**：
  - 恶劣天气降低海面拾荒航速，但会提高深海稀有鱼类和稀有物资的刷新概率。
- **昼夜光影**：
  - 夜晚拾荒视野受限，需在木筏甲板点亮探照灯照明，烘托逼真的末日海洋求生氛围。
