## 阅读与维护

各游戏的 `index.md` 是主题入口。游戏知识按概述、玩法循环、资源经济、养成、商业化与版本运营等主题组织。

当前文档、引用和发布约定统一见 [AGENTS.md](AGENTS.md)。

每项事实的证据链接指向对应游戏的 `sources/evidence.md`；该台账展示来源地址、实际引用段落与核验记录。
Agent 整理候选后，由任务注入的写入工具独立抓取来源、执行 JEV 核验并发布。
研究覆盖、证据支持和发布结果分别确认。
