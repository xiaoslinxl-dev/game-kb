# 霸业 单局战斗与职业克制系统

根据《霸业》官方开荒攻略，游戏初期玩家可通过碎片合成及英雄自选箱获得英雄，涵盖武将（【吕布】【关羽】【孙策】）、文官（【郭嘉】【貂蝉】）与全才（【赵云】【张辽】【孙尚香】）三种职业类型。这三种职业类型存在克制特点：我方英雄激活指定宿命且职业克制敌方时，造成伤害额外提升，受到伤害额外降低；职业克制方英雄部队死亡后，会对被克制方额外造成一次伤害。[@来源](../sources/systems/session-combat.md#ev-47a868e34ce0da18e53b1022e162b696)[@版本unknown]
