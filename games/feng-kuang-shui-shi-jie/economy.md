# 疯狂水世界 经济系统

《疯狂水世界》的经济系统围绕“原料打捞 - 工厂加工 - 订单变现 - 商店消费”建立，兼顾了模拟经营的物资流转与卡牌 RPG 的数值消耗。

## 1. 代币与资源分类

| 资源/代币 | 主要产出途径 | 主要消耗用途 | 紧缺度/瓶颈阶段 |
|---|---|---|---|
| **金币** | 居民订单、贸易货轮、挂机收益、月卡每日赠送 | 英雄升级、装备打造、建筑建造升级 | 全时期极度紧缺 |
| **钻石** | 主线任务、关卡通关、活动奖励、充值 | 开服第8天兰博/老侃转盘、特权商店买加速沙漏、租用自动生产 | 前期需严格囤积，不可滥抽基础池 |
| **蓝图** | 70关以上关卡挂机掉落、日常任务、居民订单、联盟商店 | 所有高级建筑的建造与升级 | 前中期极度稀缺的建造红线物资 |
| **基础原料** | 海面拾荒、拾荒船、潜水船坞、原料自选包 | 木板、金属、塑料、绳索（优先级：木板>金属>塑料>绳索） | 开荒期建造与加工基础 |
| **加工产物** | 切鱼厂（生鱼片）、材料厂/建材厂（墙纸/钢板/零部件） | 交付居民订单、提交贸易货轮 | 生产耗时长，需英雄委托缩短 |
| **加速沙漏** | 任务、特权商店（折后）、活动 | 缩短建筑建造、工厂加工、生产生产线时间 | 冲榜与快速开荒核心消耗品 |

## 2. 生产与加工产业链

游戏中的生产链呈树状阶梯延伸：

1. **零级原料**：木材、塑料、金属、绳索、生鱼、海水。
2. **一级加工品**：生鱼片、纯净水、木板、铁皮。
3. **二级加工品**：服装、日用品、建材（墙纸、零件、钢板）。
4. **高级终产物**：家具、玩具、高级军备等。

**供应链管理坑点**：贸易货轮与订单会无差别调配高级加工品。若玩家贸料将存货交掉，会导致后续建造工厂缺少墙纸等前置材料，打乱开荒节奏。

## 3. 商店交易体系

- **折扣商店**：平民玩家原则上只在 **3折及以下** 购买“传说万能碎片”与“传说技能书”，其余材料（如基础装备/普通材料）不建议消耗钻石购买。
- **特权商店**：重点购买折扣“加速沙漏”（用于第一天刷贸易港口快速升到 16 级解锁联盟）。
- **联盟商店 / 竞技商店**：优先兑换“传说万能碎片”，是零氪与平民玩家稳定提升核心英雄星级的主要来源。
