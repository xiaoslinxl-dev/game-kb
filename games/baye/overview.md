# 游戏概述

《霸业》是一款由安徽盈趣网络科技有限公司/三七互娱（半糖工作室发行）开发运营的三国阵营争霸策略手游（SLG）。游戏于2023年6月5日正式上线，主打“国潮美术风格”与快节奏“三国阵营国战”玩法。

## 基本信息

- **游戏名称**：霸业
- **Game ID**：`baye`
- **游戏类型**：三国阵营争霸策略手游 (SLG / 卡牌SLG)
- **开发/发行商**：安徽盈趣网络科技有限公司 / 三七互娱（半糖工作室）
- **上线时间**：2023年6月5日
- **游戏平台**：Android / iOS
- **官方/Store链接**：[TapTap 页面](https://www.taptap.cn/app/323779) | [官方网站](https://sgby.6711.com/)

## 核心特色与定位

1. **阵营对抗与快节奏国战**：玩家进入游戏后需要选择魏、蜀、吴三大阵营之一，围绕封地建设与阵营大地图展开城池争夺，同阵营玩家需要高度协同以扩大国家版图。
2. **国潮视觉设计**：区别于传统高写实度或重度3D沙盘SLG，游戏采用了独创的古潮/国潮美术风格，在武将立绘、UI与战斗画面上融合现代潮酷元素与古代古风。
3. **轻量化沙盘与数值深养成的结合**：降低了传统率土/三战类游戏复杂的铺路与格子铺拉扯成本，通过快节奏的大地图城池攻防与高深度的卡牌武将/兵种养成相结合，满足中重度策略玩家的对抗体验。
