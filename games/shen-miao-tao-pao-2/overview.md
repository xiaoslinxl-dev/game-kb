# 游戏概述

《神庙逃亡2》（Temple Run 2）是由美国开发商 Imangi Studios 研发，并由深圳市创梦天地科技有限公司（乐逗游戏 / iDreamSky）在中国大陆引进、本地化二次开发与长线运营的 3D 越野跑酷动作手游。自 2013 年在中国上线以来，《神庙逃亡2》凭借极其简单顺畅的操作反馈、紧张刺激的悬崖追逐体验，以及持续十余年的本土化深度改造，成长为中国移动游戏市场的国民级跑酷 IP 之一。

## 基本信息

- **游戏名称**：神庙逃亡2（英文名：Temple Run 2）
- **开发商**：Imangi Studios, LLC
- **中国发行与运营商**：深圳市创梦天地科技有限公司（乐逗游戏 / iDreamSky）
- **游戏类型**：3D 动作跑酷 / 休闲竞技
- **平台与网络**：iOS / Android / 微信小游戏；支持单机离线跑酷，并具备网络竞技场与在线活动功能。

## 本土化与演进历程

与海外原版纯粹的单机无尽跑酷不同，乐逗游戏通过获取游戏源代码，针对中国市场进行了深度的二次开发与长线商业化改造：

1. **角色与外显多元化**：引入了大量中国风角色（如叶问、柳岩、孙悟空、赵云）、动漫/节日限定角色（如安妮、比奥斯博士、万花仙子）以及配饰、翅膀（如虎虎生威、花蝶梦）、称号系统。
2. **三位一体技能体系**：在原有角色技能的基础上，增加了**坐骑系统**（如年兽、美洲豹、傲狠）与**宠物系统**（如仙灵鹤、企鹅、小香猪、冰雪精灵），形成“角色 + 坐骑 + 宠物”的多元技能组合。
3. **多人竞技与社交**：推出了竞技场/排位赛（含单人匹配与双人组队 2v2），将传统单机跑酷转变为具备实时/异步干扰对抗的轻度竞技网游。
4. **休闲减负与长线留存**：引入“黄金矿山”挂机爆金币机制、7日签到送角色、主题收集赛（如西瓜/书本/红包收集）以及观看广告积攒积分兑换角色/坐骑的“广告积分商城”，持续降低新手门槛并拉长留存。
