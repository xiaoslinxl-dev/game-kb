# 《原神》核心循环：版本更新维护与原石补偿流转

在《原神》7.1版本「往冥府的安魂歌」中，客户端更新、停服维护与原石补偿发放规则如下：

## 1. 客户端更新与停服维护节奏

- **更新维护时间**：2026/09/23 06:00开始，预计5个小时完成；各位旅行者重新下载客户端后即可继续进行体验 [证据](sources/evidence.md#ev-7e1d392654e80d5f5df0612c81ce6506)。
- **客户端更新方式**：进入游戏后，按照游戏内弹窗提示完成更新 [证据](sources/evidence.md#ev-7e1d392654e80d5f5df0612c81ce6506)。

## 2. 停服补偿与冒险等阶资格

- **原石补偿标准**：停服更新补偿原石*300（停服维护每小时补偿60原石，若提前开服，补偿将不会改变） [证据](sources/evidence.md#ev-7e1d392654e80d5f5df0612c81ce6506)。
- **补偿资格与领取期限**：停服更新补偿面向2026/09/23 06:00前冒险等阶达到5级及以上的旅行者，领取时间截至7.1版本结束前；制作组在维护完成后5小时内以游戏内邮件形式发放，邮件有效期为30天 [证据](sources/evidence.md#ev-7e1d392654e80d5f5df0612c81ce6506)。
