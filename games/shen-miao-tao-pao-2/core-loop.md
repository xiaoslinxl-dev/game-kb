# 神庙逃亡2 核心循环

《神庙逃亡2》的基础单局循环设定在神庙场景中。玩家穿越神庙夺取神像，并在恶魔守卫的追赶下进行跑酷逃亡，在持续的路程中坚持奔跑。[@证据](sources/evidence.md#ev-7bf8b8c25f036a3e60a55f1b7c1a2857)

在任务、竞赛与资源循环方面，玩家通过完成每日任务和参与排位赛获取活动道具，可在兑换商店兑换宝珠、金币与钻石；同时可将拥有的角色、神像与坐骑放入黄金矿山矿池中，获取古老矿山给予的金币馈赠，形成局内奔跑与局外收集养成的玩法循环。[@证据](sources/evidence.md#ev-a6e4b9c189e02639dd133f9d20fe1c55)
