# 核心循环

《神庙逃亡2》的核心游戏循环建立在“极简高频的操作体验”与“多元搭配的数值成长”之上。玩家通过单局跑酷获得金币、钻石及活动代币，再将资源投入到角色、坐骑、宠物与技能的升级与解锁中，进而挑战更高分数或在 PvP 竞技场中胜出。

## 核心循环图示

```text
[发起跑酷 / 竞技场匹配]
        │
        ▼
[单局操作与即时避障] ─── (拾取金币 / 能量罐 / 道具)
        │
        ▼
[单局结算与资源产出] ─── (金币、钻石、活动代币、赛季积分)
        │
        ▼
[养成与解锁系统]
  ├── 角色 / 坐骑 / 宠物 升级与技能强化
  ├── 装备翅膀 / 佩戴称号与金币皮肤
  └── 黄金矿山挂机产出与宝珠抽卡
        │
        ▼
[追求更高目标] ─── (刷新无尽高分 / 冲击排位赛高段位 / 完成限时收集)
```

## 核心步骤解析

1. **单局跑酷（Core Gameplay）**：
   - 玩家滑动屏幕（上跳、下蹲、左转、右转）与倾斜设备（重力感应左右移动）来避开树根、火焰、断崖等障碍，同时被恶魔守卫（追击猴子）紧随其后。
   - 沿途拾取金币与特殊道具（护盾、磁铁、加速暴走、金币爆发）。
2. **三位一体技能释放**：
   - 攒满能量槽后双击屏幕触发主角色暴走/护盾等技能。
   - 坐骑与宠物的被动/主动技能在特定条件下自动触发（如绊倒后概率生成护盾、加速距离延长、敌方技能失效等）。
3. **结算与资源转化**：
   - 根据奔跑距离、金币收集数及得分倍率结算金币与经验。
   - 竞技场胜负产生段位积分；活动期间产出特定收集道具（如西瓜、书本、扳手）。
4. **长线养成与反馈**：
   - 消耗金币升级基础通用属性（如 Save Me 续关打折、磁铁时长、金币价值提高）。
   - 使用钻石/宝珠/人民币解锁 S/A 级角色与神兽坐骑，大幅提升基础得分加成与竞技对战优势。
