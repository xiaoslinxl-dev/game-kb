# 疯狂水世界 核心循环

《疯狂水世界》的核心体验驱动力来自于“拾荒生存 - 基地扩建 - 英雄推关 - 联盟协作/城战 - 征服赛季”的多重闭环循环。

---

## 1. 核心闭环结构

```text
  [海面拾荒/深海潜水/钓鱼捕捞] ──(呼应现实“净海行动”)
            │
            ▼ (收集木板、金属、塑料、绳索、蓝图)
  [加工生产与居民订单] ───(升级/委任)───► [扩建海上城邦/人口突破]
            │                                     │
            ▼ (获得经验、金币、加速沙漏)            ▼ (解锁高阶工厂/兵工厂/英雄委派)
  [卡牌推关与挂机放置] ◄───(提升战力/装备)─── [英雄抽卡与升星养成]
            │
            ▼ (获取徽章/藏品/万能碎片/水母币/竞猜积分)
  [联盟商船协作 / 巅峰擂台赛 / S6+ 征服赛季「黑潮」8 联盟水之都争霸]
```

---

## 2. 四层洋葱式融合驱动模型（2026年9月行业深度解构）

据 2026 年 9 月 16 日行业深度复盘（Enjoy出海），《疯狂水世界》的底层成功密码在于将多重品类拆解为“层层嵌套、递进展开”的四层洋葱式架构：

```text
  ┌─────────────────────────────────────────────────────────────┐
  │ 4. Light SLG & Conquest Season (16级/S6+ 征服赛季 8 联盟对决) │
  │    ┌───────────────────────────────────────────────────┐    │
  │    │ 3. Card Battle (5v5 放置推关、数值养成与反哺生产)   │    │
  │    │    ┌─────────────────────────────────────────┐    │    │
  │    │    │ 2. Simulation (生产链、12元自动特权、订单)│    │    │
  │    │    │    ┌───────────────────────────────┐    │    │    │
  │    │    │    │ 1. Survival (捡垃圾、钓鱼、拾荒)│    │    │    │
  │    │    │    └───────────────────────────────┘    │    │    │
  │    │    └─────────────────────────────────────────┘    │    │
  │    └───────────────────────────────────────────────────┘    │
  └─────────────────────────────────────────────────────────────┘
```

1. **第一层：Survival 负责起手（秒懂吸量）**：
   - 游戏开局脚下只有一块漂在海上的破木板，第一件事就是“捡垃圾”。捡废料、救幸存者、钓鱼、拾荒，操作极其简单直观，前 30 分钟不露任何重度 SLG 元素，让泛用户在 3 秒内建立代入感。
2. **第二层：Simulation 撑住日常（经营留存与第一变现漏斗）**：
   - 玩法迅速进入“采集—建造—加工”的生产循环。随着资源种类增加、加工链拉长，玩家进入供需瓶颈，顺势打开了**12 元解锁材料自动生产**的核心变现切口。
3. **第三层：Card Battle 承接成长（双向赋能）**：
   - 推关、竞技场、资源副本驱动英雄等级、星级、专武和徽章养成。英雄不仅负责战斗，更拥有内城委派提速技能，形成“基地养人，人反哺效率”的良性反哺。
4. **第四层：Light SLG 补上社交、扩张与赛季（轻量化大世界）**：
   - 16 级压后开放大地图与联盟。无主城自由拆家，同盟资源点独立，以舰队耐久度替代死兵惩罚；而在 S6 及后续版本中全面升级为 **S6+ 征服赛季**，引入 8 联盟争夺水之都与「黑潮」动态禁战天候，带来更深度的 GvG 战术博弈。

## 3. 三层核心循环详解

### 第一层：经营与生存闭环（短周期：分钟/小时级）

1. **资源收集与自动化进阶**：
   - 基础建材按收集优先级排序：**木板 ＞ 金属 ＞ 塑料 ＞ 绳索**，是建造与扩建木筏的绝对刚需。
   - **资源收集器**：开荒初期优先升至 3 级，免费解锁自动打捞功能，极大降低手动拾取频率。
   - **拾荒船**：建造后即可出海拾荒；升至 2 级后解锁自动拾荒，航行速度同时提升 20%。拾荒过程中需警惕深海鲨鱼袭击，若被鲨鱼撞击累计达 3 次则拾荒任务失败。
   - **垂钓捕捞**：提供生鱼基础原料，达到指定等级后解锁自动钓鱼，钓获新鱼种可累积鱼类图鉴积分并解锁永久属性加成。
   - **深海潜水**：23 级解锁潜水船坞，深入沉船与沉没遗迹打捞高阶蓝图、稀有金属与藏品。
   - **“净海行动”价值呼应**：游戏启动的“净海行动”（联合广州市海洋双碳研究会）将游戏内“海面拾荒、物资清理与资源再循环”的玩法设定与现实中海岸线垃圾清理、海洋碳汇保护深度咬合，让玩家的每一次基础打捞都具备了现实环保的价值投射。
2. **加工制造与基础循环构建**：
   - 14 级前优先解锁工作台、切鱼厂与种植农场，建立**“收集－生产－储备”**的完整基础循环。
   - 通关第 100 关后解锁**“海上田园”**系统，在木筏上开垦农田种植农作物，为居民订单与对外贸易储备粮食原料。
   - 51 级解锁【兵工厂】，扫荡海盗获取原料加工城市工事耗材。
3. **订单交付与人口增长**：
   - 完成居民委托订单与贸易港口货轮订单，获取玩家经验（EXP）、金币与加速沙漏。
   - 建设民居增加基地人口，建造发电站、医院、礼堂等设施打破人口上限门槛，满足新建筑与工厂升级的人口红线。

### 第二层：养成与推关闭环（中周期：天级）

1. **战力养成与词条精炼**：
   - 消耗金币与经验提升英雄等级（最高为玩家等级 5 倍）。
   - 英雄升至 **3 星** 解锁核心质变技能；利用【洗刷锁】在超凡装备和海兽洗炼时锁定核心词条（如闪避率、攻速、暴击），搭配蓝色装备可实现 3 秒快速锻造。
   - 配置专属武器与战术核芯（如【登峰】核芯）。
   - 达到 51 级后可在远征商店每日消耗远征币兑换【超凡英雄万能碎片】，拓宽平民升星途径。
2. **放置推关（PVE）与关键突破**：
   - 通关主线关卡，开局第一天强烈建议将关卡推至 **70 关以上**，通关 70 关后挂机收益正式掉落建造极缺的核心物资**“蓝图”**。
   - 关卡支持自动连续推关与 10 秒后跳过战斗，挂机持续产出金币、经验、蓝图与随机徽章。
   - **800 关“双博士”卡点**：开荒期关键分水岭，敌方双博士高爆发压制，通常需切换闪避增强阵或初始能量阵，通过 [机器屠夫](/entities/units/ji-qi-tu-fu.md) 的上下位飞钩机制精准拉取并后置保护主 C 兰博多次凹关突破。
3. **资源反哺**：
   - 关卡产出的蓝图与沙漏反哺基地工厂升级，提高生产效率与高阶建材产出。

### 第三层：社交与对抗闭环（长周期：周/赛季级）

1. **联盟协作与商船出海**：
   - 16 级加入联盟，享受全员生产互助与轻质钢每日互刷功勋；参与限时 3 天的【联盟商船】订单交付（半数以上成员参与倒计时结束自动启航），赚取水母币兑换黄金徽章自选、超凡藏品万能碎片与超凡技能书。
2. **S6+ 征服赛季与全新世界剧本「黑潮」（GvG）**：
   - 从 S6 赛季起全区服正式改制为**“征服赛季”**，首发「黑潮」剧本，由 4 联盟升级为 8 联盟对决，争夺中心奇观“水之都”。
   - 引入动态黑潮禁战期、战略硅矿（每日限 30 次抢占）与巨轮打捞，赛季结算按盟主战利品分配机制发放赛季币与稀有奖励。
3. **天梯竞技与巅峰对决（PVP）**：
   - 跨服竞技场每日天梯排行结算；参与【巅峰擂台赛】（利维坦前 128 名淘汰赛），全员参与多阶段赛事竞猜赚取永久竞猜积分，构建竞技与泛娱乐并重的高粘性社区。
