# 霸业 核心循环

《霸业》的核心循环围绕三国阵营对抗展开。玩家在开局选择魏、蜀、吴阵营，通过建设封地与招募三国名将提升实力，本国玩家协同攻城掠地并扩张国家势力版图。[@证据](sources/evidence.md#ev-5c0a42a2e4ddfa7d9dea036bc51d3992)

在大地图实时国战层面，游戏采用创新棋盘连城大地图机制，战术操作包括全民攻城、突进封路、残兵撤退与密道突袭。[@证据](sources/evidence.md#ev-ed3b56421d6e0aa6e266cc67f3752907)

战斗与扩张的回馈驱动方面，攻城拔寨、扩张版图以及参与国家建设和国战，可免费瓜分国库分红海量元宝，用于后续封地与实力建设，形成以战养战的循环闭环。[@证据](sources/evidence.md#ev-b5f6eb080b8402d2ed19e2a7358a3c60)
