# 疯狂水世界 数值与养成系统

《疯狂水世界》的战力成长体系分为“基础属性（等级/升星/技能）”与“额外加成（装备/精炼词条/徽章/海兽/藏品）”两大核心支柱，并提供了无损重生的养成容错机制。

## 1. 玩家等级与建筑门槛

- **等级上限与内容扩展**：S7 赛季玩家等级上限提升至 **100 级**，主线闯关新增至 **4300 关**，试炼副本扩展至 **140 关** [1.7]。
- **玩家经验（EXP）获取途径**：主线/日常/支线任务 > 居民委托订单 > 建筑建造升级 > 关卡推图（30 EXP/关）> 贸易货轮。
- **人口红线机制**：高级建筑建造与升级必须达到对应的人口需求。人口通过民居（小型/中型/大型）增加，人口上限需通过发电站、医院、礼堂、水上乐园等特殊建筑打破。
- **70 关分水岭**：开局第一天须尽快将关卡推至 70 层以上，通关 70 层后挂机奖励开始掉落稀缺资源“蓝图”。

## 2. 英雄养成体系

### 升星与技能解禁
- **等级上限**：英雄等级上限为当前玩家等级的 5 倍，升级消耗英雄经验与金币。
- **升星（质变节点）**：英雄达到 **3 星** 才能解锁核心的第 4 技能。1 技能（主动大招）与 4 技能（被动核心机制）共同决定英雄强度的质变。
- **万能碎片分配**：推荐分配顺序为：[大嘴山姆](/entities/units/da-zui-shan-mu.md)（懂王拉到3星解锁全屏嘲讽） → [兰博](/entities/units/lan-bo.md)（拉到3星开启攻速红温爆发） → [巫师老侃](/entities/units/wu-shi-lao-kan.md)（拉到3星提供全队护盾增伤）。
- **无损重生**：游戏提供无损重生功能，英雄重生 100% 返还升级经验与进阶材料。但**传说万能碎片与传说技能书为不可返还稀缺资源**，必须慎重投给核心 T0 英雄。

### 专属武器（专武）
- 英雄激活专属武器后获得特殊机制突破。
  - [兰博](/entities/units/lan-bo.md)：专武提供免疫致死与锁血输出。
  - [大嘴山姆](/entities/units/da-zui-shan-mu.md)：专武大幅提高自身护盾厚度与反弹伤害。
  - [小丑杰克](/entities/units/xiao-chou-jie-ke.md)：专武 60 级解锁高额暴击爆发收割。

## 3. 装备、精炼与徽章系统

- **装备三部位**：
  - **枪械**：能量输出英雄优先打造（如兰博）。
  - **兵刃**：物理输出与刺客英雄优先打造（如千代、铁腿红魔）。
  - **防具**：前排主坦英雄优先打造（如大嘴山姆、探案双子星）。
- **超凡装备精炼（Affixes Refining）**：
  - 精炼属性分为基础属性与额外属性，关键洗练等级节点为 **65 级**（解锁第 1 词条）与 **100 级**（解锁第 2 词条）。
  - **主 C 词条优先级**：攻速（兰博需控在 1.0-1.2 区间）、暴击率、暴击伤害、攻击力百分比、抗性穿透。
  - **主坦词条优先级**：闪避率（大嘴山姆需堆至 75% 闪避阈值）、伤害减免、生命值百分比、暴击抗性。
  - **辅助/控场词条优先级**：攻速（加速技能循环）、技能强度、生命减伤。
- **徽章品质**：沉木 < 黑铁 < 青铜 < 白银 < 黄金。黑铁及以上品质自带随机词条，无法洗练，高层关卡挂机产出高阶徽章。

## 4. 海兽培育与藏品套装

- **海兽系统（23级解锁培育室）**：
  - [鳌蟹](/entities/units/ao-xie.md)：超凡防御海兽（全队双抗、护盾吸收、霸体免控）。
  - **铁甲人鱼**：S5 赛季登场的限定超凡海兽，提供反伤与减益净化 [1.7]。
  - [海豚](/entities/units/hai-tun.md)：传说万金油海兽（为 3 名友军持续回血与高额减伤）。
  - **鲨鱼/章鱼**：针对敌方回血阵容与提供群体眩晕。
- **藏品套装**：
  - **奇珍异兽博物馆**：美人鱼联动限定橙藏品套装，提供全队攻击与生命大幅加成 [1.7]。
  - **荣耀之巅**：赛季商店兑换的全新红藏品套装，提供 PVP 城战伤害与减伤增益 [1.7]。
  - **财源滚滚**：提供基地生产/建造加速与日常订单金币加成。
