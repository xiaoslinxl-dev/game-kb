# 局内战斗机制

## 暴击与格挡计算公式

官方公示的游戏属性计算公式如下：
- **暴击**：暴击率 = 暴击率 /（格挡率 + 暴击率 + 100%）。
- **格挡**：格挡率 = 格挡率 /（格挡率 + 暴击率 + 100%）。[@来源](../sources/systems/session-combat.md#ev-8f395578806c379c8dee51768bfb7bd8)[@版本unknown] [@变更](../.changelog/2026-10-13/change-6754ecd56d33402383fe2b9bc2aec23a.json)

## 图腾防御与伤害结算规则

- **伤害公式**：伤害 = 原伤害 + 防守方防御 * 0.15 *（攻击方无视防御 - 防守方防御加成）。
- **最终伤害区间限制**：造成的最终伤害不得超出原伤害 1.6 倍，不会低于原伤害的 0.4 倍。
- **相关攻防属性**：
  - 前军攻击时，无视XX%防御；
  - 后军攻击时，无视XX%防御；
  - 英雄技能攻击时，无视XX%防御；
  - 受到前军攻击时，加成XX%防御；
  - 受到后军攻击时，加成XX%防御；
