# 霸业 封地建筑与升级系统

根据2024年8月《霸业》新手阶段攻略资料，玩家推进主线任务时可同时提升府邸等级至8级。每次升级府邸都需要满足相应的建筑升级条件，而每次建筑升级都会消耗一定的时间；若不想等待，可使用沙漏进行加速，也可以使用元宝直接完成建筑升级，攻略作者建议将元宝留到后续使用。[@来源](../sources/evidence.md#ev-5b25c8366020f15aa7797017ee8333f4)

## 新手阶段建筑配置与等级参考

在攻略所述的新手发展阶段中，爵位记录可提升至中大夫，府邸等级可达8级。拜将台可升至3级，军营共有4个可升至8级。此外，还有8个资源建筑可达8级，演义台和群英馆可提升至2级和8级，辎重站和书院可达8级和2级，码头和商肆等级最低分别为1级。攻略作者基于个人对游戏的理解，给出建议的升级顺序为：府邸 > 8个资源建筑 > 4个军营 > 书院 > 演义台、群英馆 > 辎重站（码头、商肆只有1级）。[@来源](../sources/evidence.md#ev-ba174ac4ce69c863b9cd89dc12f72f4f)

## 建筑升级消耗与资源补充

每次建筑升级都会需要一定的材料。前期如果升级建筑次数较多，那么木头会十分缺少。所以在建筑升级的过程中，可以同步去攻城做巡城任务，每次巡城都会获得一定量的资源。[@来源](../sources/evidence.md#ev-44c02d60ff846bf837a0d8850176ec1b)
