# 核心循环

《斗罗大陆：猎魂世界》的核心循环建立在“开放世界探索/副本挑战 → 资源获取（魂环/魂核/觉醒券） → 武魂抽卡与魂环/魂核/魂骨养成 → 战力提升 → 挑战高阶副本/跨服 PvP”的经典 MMORPG + Gacha 循环链上。

## 1. 每日/每周核心体验

- **日常循环**：
  - 完成每日活跃任务（8 个任务，固定产出 2000 魂师经验与武魂觉醒券）。
  - 体力消耗：消耗体力挑战拟态副本、猎魂魂兽（刷取魂环与突破材料）。
  - 宗门互动：宗门建设捐赠、完成宗门任务积累宗门贡献度，在宗门商店兑换武魂潜能激活与升级材料。
- **周常与限时循环**：
  - 邪化兽王（每日 3 次免费挑战组队副本，掉落千年/万年魂环）。
  - 猎魂悬赏与深渊巨兽（消耗悬赏令组队开启，产出 SSR 级魂骨与万年魂环）。
  - 限时周常玩法（如「演武·元素掌控」、「邪魇入侵」、「远征计划」等，提供大量限定觉醒券与十万年魂核/魂骨资源）。
  - 「斗魂对决」赛季跨服竞技场对战。

## 2. 战力反馈机制

战力的提升直接解锁更高层级的猎魂副本（如 80 级开启的【暗星炽翼】强敌副本）、更高的地图区域（如杀戮之都、七宝山脉）以及竞技场更高的段位排名。
