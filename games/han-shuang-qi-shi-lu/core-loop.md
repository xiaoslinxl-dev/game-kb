# 寒霜启示录 核心循环

《寒霜启示录》的总体玩法闭环由“城镇经营与离线放置积累 → 战力培养与小队搭配 → 探索关卡与世界远征 → 产出回流城镇与扩张”构成。

## 1. 城镇建设与领地扩张循环

玩家以一座熔炉为核心起点，通过融化冰雪与开拓领地推进城镇建设，合理规划人力分配与各类资源投入以建设繁荣小镇。[@证据](sources/evidence.md#ev-e769429dc34475566649d00463e18ec9)

## 2. 放置挂机与日常资源补给

在放置收益机制下，玩家可通过一键派遣英雄自动积累离线资源，保证在离线期间仍能获得持续资源增长，维持稳定的生存与建设节奏。[@证据](sources/evidence.md#ev-0785da21cf96574e071fbeef4d3c2fa7)

## 3. 伙伴战斗与小队策略循环

英雄战队是向外探索和御敌的关键。所有伙伴实行等级共享机制以降低培养成本，玩家通过灵活组合不同英雄的技能打造制胜小队。[@证据](sources/evidence.md#ev-894928b1f0d54e754b3ad24dd527d33d)

## 4. 探索关卡挑战与战力验证

“探索”模式构成了核心战斗体验与实力检验场。玩家带领小队挑战重重关卡，关卡推进程度直接决定所获得的奖励和资源规模，征服的关卡越多，获得的回报越丰厚。[@证据](sources/evidence.md#ev-099042e2152380817ab06ca2b41dd62d)

## 5. 外向探索与世界远征回报

除城镇内探索模式迎战敌方英雄小队外，游戏还设有包含世界地图战斗的“远征”模式。玩家通过持续完成探索关卡与远征任务击败敌军，源源不断地带回外部资源与丰厚奖励，重新投入城镇升级与小队进阶，形成完整的玩法正反馈闭环。[@证据](sources/evidence.md#ev-d492a0373ea8b448e1356071a40ff992)
