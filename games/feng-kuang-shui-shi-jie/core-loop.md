# 疯狂水世界 核心循环

《疯狂水世界》的核心体验驱动力来自于“拾荒生产 - 基地扩建 - 英雄推关 - 联盟城战”的多重闭环循环。

## 1. 核心闭环结构

```text
  [海面拾荒/深海潜水/钓鱼]
            │
            ▼ (获取木材、金属、塑料、蓝图)
  [加工生产与居民订单] ───(升级/委托)───► [扩建海上城邦/人口突破]
            │                                     │
            ▼ (获得经验、金币、加速沙漏)            ▼ (解锁高阶建筑/英雄位)
  [卡牌推关与挂机放置] ◄───(提升战力/装备)─── [英雄抽卡与升星养成]
            │
            ▼ (获取徽章/藏品/万能碎片)
  [联盟城战与大地图争夺]
```

## 2. 三层循环详解

### 第一层：经营与生存闭环（短周期：分钟/小时级）

1. **资源收集**：通过海面点击/自动拾荒船打捞木材、金属、塑料；在钓鱼台捕鱼；在潜水船坞搜寻高阶藏品与深海稀有物资。
2. **加工制造**：在切鱼厂制作生鱼片，在材料厂/建材厂加工墙纸、钢板、零部件等半成品与成品。
3. **订单交付与人口增长**：完成居民订单与贸易港口货轮需求，获得玩家经验（EXP）、金币与藏品材料。建设民居增加人口，建造发电站/医院等设施打破人口上限，满足新建筑与工厂升级的建造门槛。

### 第二层：英雄养成与关卡推图闭环（中周期：天级）

1. **挂机推图**：自动推进关卡（推关越深挂机收益越高，前 70 关为蓝图掉落的关键分水岭）。
2. **战斗反馈**：通过挂机与推关掉落徽章、装备锻造材料与英雄经验，提升 5 人出战小队战力。
3. **英雄成长**：使用招募券与万能碎片进行英雄升星（全员 3 星解锁核心第 4 技能），解锁/升阶专属武器，洗练装备/徽章词条（攻速、闪避、暴击），反哺推关进度与高难副本（如双博士关卡）。

### 第三层：联盟争霸与周榜轮换闭环（长周期：周/赛季级）

1. **联盟互助与科技**：玩家达到 16 级解锁联盟后，发起生产互助、研发联盟科技（优先种子、汽油等资源科技，后点战斗与攻城耐久功勋科技）。
2. **大地图城战与矿产争夺**：联盟成员在大地图占领加工厂、争夺硅矿、攻打要塞与城池，争夺功勋与赛季城战排名。
3. **周度活动循环**：根据每周固定轮换的主题榜单（资源竞赛/海商王/赛季转盘抽卡）囤积资源冲榜，获取限定超凡英雄与赛季专属红藏品。
