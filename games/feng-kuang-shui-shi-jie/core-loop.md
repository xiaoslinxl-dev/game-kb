# 疯狂水世界 核心循环

《疯狂水世界》的核心体验驱动力来自于“拾荒生存 - 基地扩建 - 英雄推关 - 极限试炼 - 联盟协作/城战 - 征服赛季”的多重闭环循环。

---\n
## 1. 核心闭环结构

```text
  [海面拾荒/深海潜水/钓鱼捕捞] ──(呼应现实“净滩行动”四大阵营减碳冲刺)
            │
            ▼ (收集木板、金属、塑料、绳索、蓝图)
  [加工生产与居民订单] ───(升级/委任/水姆特权/双节35%加速)───► [扩建海上城邦/人口突破]
            │                                                               │
            ▼ (获得经验、金币、加速沙漏、月爪与盲盒卡)                       ▼ (解锁高阶工厂/兵工厂/英雄委派)
  [卡牌推关、极限试炼与放置] ◄───(提升战力/核芯/阵型)────────── [英雄抽卡、翻牌池、双节盲盒与流转核芯]
            │                                                               ▲ (远征商店每周 20 枚超凡碎片)
            ▼ (获取徽章/藏品/万能碎片/水母币/竞猜积分)                              │
  [联盟商船协作 / 巅峰擂台赛 / S6+ 征服赛季「黑潮入侵」8 势力水之都 280+ 地块争霸]
```

---\n
## 2. 四层洋葱式融合驱动模型（行业深度解构）

据 2026 年 9 月行业权威复盘（Enjoy出海），《疯狂水世界》的底层成功密码在于将多重品类拆解为“层层嵌套、递进展开”的四层洋葱式架构：

```text
  ┌────────────────────────────────────────────────────────┐
  │ 第四层：重度 4X SLG 大地图与征服赛季 (S6+ 黑潮入侵 8 势力水之都争霸)│
  │   ┌──────────────────────────────────────────────────┐   │
  │   │ 第三层：轻度放置卡牌 RPG (5v5 站位/战术飞钩/流转核芯)│   │
  │   │   ┌──────────────────────────────────────────┐   │   │
  │   │   │ 第二层：模拟经营建造 (切鱼厂/51级兵工厂/居民订单) │   │   │
  │   │   │   ┌──────────────────────────────────┐   │   │   │
  │   │   │   │ 第一层：末日拾荒吸量点 (开局单手打捞垃圾)│   │   │   │
  │   │   │   └──────────────────────────────────┘   │   │   │
  │   │   └──────────────────────────────────────────┘   │   │
  │   └──────────────────────────────────────────────────┘   │
  └────────────────────────────────────────────────────────┘
```

1. **第一层（0~10分钟）：超休闲吸量层**：
   - 玩家进入游戏的第一动作是点击海面飘来的塑料瓶、浮木和废铁罐（无操作门槛，单手完成）；
   - **吸量转化密码**：素材呈现“开局一根钩，物资全靠捞”，直接击中泛用户对末日漂流题材的好奇心，以近乎超休闲游戏的操作实现第一步极高转化。
2. **第二层（10分钟~第3天）：模拟经营与家园建设层**：
   - 捞上来的物资不再只是数字，而是用于扩展木筏网格、建造切鱼厂、材料厂和海水净化器；
   - 引入居民委托、货轮订单与“12 元自动生产”特权切口，通过生产线扩建与人口规模跃升带来模拟经营的深度正反馈。
3. **第三层（第3天~第2周）：放置卡牌 RPG 养成层**：
   - 基地遭受变异海怪（章鱼、鲨鱼）与末日海盗劫掠，驱动玩家开启 5v5 自动卡牌对战；
   - 核心主 C（如 [兰博](/entities/units/lan-bo.md)）、战术飞钩（[机器屠夫](/entities/units/ji-qi-tu-fu.md)）与嘲讽主坦（[大嘴山姆](/entities/units/da-zui-shan-mu.md)）成型，英雄升星、核芯镶嵌与徽章洗炼成为中线核心战力支撑。
4. **第四层（第2周以后）：重度 SLG 领地战与征服赛季层**：
   - 跨服大地图开放，玩家加入联盟参与世界城池集结、远洋货轮争夺、硅矿采集；
   - S6+ 升级为「黑潮入侵」征服赛季，8 势力在 280+ 地块宏大沙盘上向内海“水之都”发起向心决战。游戏完成了从泛娱乐小游戏到重度付费 SLG 的无缝演进。

## 3. 驱动闭环的微观运转机制

### 第一层：生产与建造循环（短周期：分钟/小时级）

1. **海面拾荒与全服减碳联动**：
   - 基地周围不断漂流木材、废金属、塑料与绳索，手动打捞或委派拾荒船自动收集；
   - 呼应线下“净海行动”，游戏内“净滩行动”四大阵营手动打捞持续折算全服减碳值。
2. **加工流水线与特权加持**：
   - 建立切鱼厂、材料厂、海水淡化车间与 51 级兵工厂。海獭专属宠物皮肤【有獭有福】（生产+5%）叠加双节 30% 特权，全厂提速飙升至 35%；
   - 配合 12 元自动生产特权与水姆商店周特权（全场5折+周末退半），原料与建材产出周期缩短一半以上。
3. **订单履约与金币回流**：
   - 生产的成品用于交付居民委托与贸易货轮订单，换取金币、建筑蓝图、加速沙漏与双节专属代币「月爪」。

### 第二层：数值与战力成长循环（中周期：天级）

1. **英雄与战术核芯**：
   - 配置专属武器与战术核芯（如【登峰】核芯、【流转】核芯）；根据敌方站位配置 4 种新阵型（伤害增加/减免、控制抗性Ⅰ/Ⅱ）；
   - **远征商店超凡碎片常态化**：达到 51 级后可在远征商店消耗远征币兑换【超凡英雄万能碎片】（每周上限 20 枚），大幅缓解平民玩家只够养 1~2 个超凡英雄的严重瓶颈。
2. **放置推关（PVE）与关键突破**：
   - 通关主线关卡，开局第一天强烈建议将关卡推至 **70 关以上**，通关 70 关后挂机收益正式掉落建造极缺的核心物资**“蓝图”**；
   - 关卡支持自动连续推关与 10 秒后跳过战斗，挂机持续产出金币、经验、蓝图与随机徽章；双节期间挂机与闯关额外掉落活动道具「月爪」与盲盒卡；
   - 800 关面对“双博士”卡关点时，需适时后置 [机器屠夫](/entities/units/ji-qi-tu-fu.md) 钩走对称位关键单位打破僵局。
3. **循环挑战「极限试炼」与双节特色玩法**：
   - 周期性限时开启（每期持续 3 天，S1-S3 赛季在第 25~27 天开启，S4 赛季起在第 22~24 天以及第 46~48 天开启）；
   - 针对困难模式登榜需求，平民社区提炼出以李忠诚+机修罗莉机械召唤流拆分二队承伤的通用方案；
   - **双节特色玩法「海底捞月」与「国庆佳节」演进（9月29日实测）**：
     - 海底捞月今日（9月29日）正式解锁第 16-20 关，实测第 20 关达到顶格 **10 月饼 + 100 钻石 + 阶段通关大奖宝箱**，正式接替第 10 关成为全服最新最优扫荡标杆！持续运用出钩 4 诀（秒退防扣钩、刁钻物位重置刷新、鲨鱼悬停/顶点受击判定、空钩清场预判）实现三星通关；
     - 双节第三大板块「国庆佳节」开启倒计时 1 天，明日（9月30日）正式启动，重磅上线全新特色策略卡牌玩法「水世界牌」（人机/匹配 3 战场三局两胜，冲 3:0 完胜翻倍刷心动值）与「机械蛞蝓入侵」再临补充入场券，提交材料累积心动值阶梯解锁戴安娜皮肤【黄金比例】与全新连胜特效【我厉害不】；
     - 节日商店确立**南海遗珍藏品 4 件套（必换）**、超凡红碎/红海兽、洗刷锁与流转【储存生命】核心兑换链。

### 第三层：社交与对抗闭环（长周期：周/赛季级）

1. **联盟协作与商船出海减负**：
   - 16 级加入联盟，享受全员生产互助与轻质钢每日互刷功勋；参与限时 3 天的【联盟商船】订单交付。优化后**只要半数以上船员登船，倒计时结束即自动启航**，赚取水母币兑换黄金徽章自选、超凡藏品万能碎片与超凡技能书。
2. **S6+ 征服赛季世界剧本「黑潮入侵」（9月29日实战与合服后沙盘攻防全面白热化）**：
   - 从 S6 赛季起全区服正式改制为**“征服赛季”**，首发「黑潮入侵」剧本，由 4 联盟升级为 8 势力对决，争夺中心奇观“水之都”；
   - 9 月 26 日合服生效后的第 4 天（开季第 9 天），各战区新组建的主力同盟全面入局，沙盘战局围绕内海水之都外围防线关隘展开攻防决战；
   - **大地图沙盘地块扩充至 280+ 块**，整点万吨货轮（2艘）、中型货轮（10艘）、小型货轮（12艘）与硅矿（高等14/中等32）成倍增加；
   - **黑潮禁战与禁铺路规则**：黑潮吞没的城市不可宣战且不可用于铺路连地，迫使联盟必须根据黑潮涨落规划进军节奏；
   - **汽油维修成本递增新机制**：舰队在外海维修耐久度所消耗的汽油随距主城距离成正比递增，促使战盟严格形成“攻占加油站前哨 - 建立中继站 - 集中油料推进”的严谨组织战术循环；
   - **尾刀抢城战术**：最后一击决定城池归属，联盟采取末段耐久集火与外围阻截战术确保攻城成果。
3. **巅峰擂台赛与全民竞猜**：
   - 跨服积分赛前 128 名争夺冠军，全民参与竞猜投票赚取积分，积分永久保留，在赛事商店换取登峰核芯与超凡碎片。
