# 雷教授 (Lei Jiao Shou)

新手“五件套”之一，前期免费提供的能量群体输出卡。

## 1. 核心属性与定位

- **职业与类型**：能量远程 AOE 输出。
- **获取途径**：新手教程与开局必定获得，属于极易获取的传说英雄。

## 2. 养成建议

- 开局第 1-3 天可作为主 C / 副 C 升级推关，但在获得 [兰博](/entities/units/lan-bo.md) 后不建议消耗稀缺的传说技能书给雷教授升级技能。
- 达到中期后可利用游戏的“无损重生”机制，将雷教授升阶材料全部无损返还并投入给国家队核心主 C。
