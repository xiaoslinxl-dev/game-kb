# 原神 核心循环

## 探索行动与环境互动

《原神》是一款开放世界冒险游戏。玩家踏入「提瓦特」后需合理规划体力以翻山越岭或横渡江河见到新风景，在探索中可上前探究游荡的仙灵与奇异装置。[@来源](sources/evidence.md#ev-b35a07bcfbc151fc9aac291cd1c2f47f)

## 队伍养成与秘境挑战

在冒险旅途中，玩家结识能力独特的伙伴并摸索最佳队伍搭配，使用旅途中搜集的材料强化角色，最终征服大陆上的魔物与秘境。[@来源](sources/evidence.md#ev-d6466a22af2e5807a75891a8d8154d9c)

## 进度循环与等阶机制

冒险阅历是游戏内决定进度的数值，影响游戏的强度。当获得足够多的冒险阅历时，将消耗掉冒险阅历以提升冒险等阶。世界等级决定了冒险等阶的软上限，目前冒险等阶的硬上限是60级；当冒险等阶达到上限后，溢出的冒险阅历将会以1:10的比例转化为摩拉。[@来源](sources/evidence.md#ev-6a180d3073af290e167b58a7df1017dc)
