# 核心循环

《霸业》的游戏循环建立在“封地资源产出 → 武将与部队养成 → 阵营城池争夺（国战） → 战功与爵位提升 → 封地与特权扩张”的闭环链路之上。

```
+-------------------------------------------------------+
|                    封地建设 / 产业收益                  |
|          (产出粮草、银两、木材、铁矿等基础资源)           |
+---------------------------+---------------------------+
                            |
                            v
+-------------------------------------------------------+
|                    武将招募与养成                      |
|         (抽卡、升级、突破、技能与兵种科技研究)        |
+---------------------------+---------------------------+
                            |
                            v
+-------------------------------------------------------+
|                  阵营沙盘与城池攻防                   |
|        (刺史战、州牧战、称王战、国家城池铺路攻占)     |
+---------------------------+---------------------------+
                            |
                            v
+-------------------------------------------------------+
|                  战功/爵位与国家福利                  |
|          (提升阵营官职、获取高阶俸禄与资源加成)       |
+-------------------------------------------------------+
```

## 1. 玩家日度行动循环（Daily Loop）

1. **封地管理与资源收割**：每日登录收割封地建筑与产业收益（粮草、银两、强化材料等），进行建筑升级与资源调配。
2. **日常副本与PVE开荒**：参与“演义之路”、“名将交锋”、“藏兵阁”、“群英会”等PVE玩法，收集武将碎片、装备图纸与突破材料。
3. **阵营国战与城池争夺**：参与实时或定时开启的国战攻防，派遣部队前往前线攻打敌对阵营城池或进行据点防守。
4. **战功结算与官职提升**：通过国战杀敌和攻城结算战功，提升个人官职与爵位，领取每日国家俸禄与排名奖励。

## 2. 中长线赛季/阶段循环（Long-term Progression Loop）

- **前期开荒（1-7天）**：快速建立封地基本设施，完成“七日狂欢”与新手试炼任务，培养核心开荒武将（如马超等），解锁高级兵种。
- **中期阵营扩张（2-4周）**：同阵营玩家组建军团，发起“刺史战”与“州牧战”，逐步打通郡县至州府的连通道路，争夺核心资源城池。
- **后期称王与一统（赛季末）**：发动“称王战”与皇城总攻，决定赛季胜利阵营，获得赛季专属称号、顶级神器与高阶武将奖励，随后进入新的赛季或版图重置。
