# 市场定位与竞品分析

## 1. 市场定位

《神庙逃亡2》是中国移动游戏史上生命周期最长的**国民级 3D 悬崖跑酷手游**之一。它与《地铁跑酷》（Subway Surfers）共同构成了创梦天地（乐逗游戏）在休闲跑酷赛道的两大支柱产品，占据中国跑酷市场头部份额。

- **目标受众**：涵盖泛休闲玩家、中小学生、怀旧老玩家以及对轻度 PvP 对战感兴趣的竞技玩家。
- **核心卖点**：第一人称视角后方的追逐压迫感、悬崖倾斜转弯的操作手感、丰富的中国风角色/坐骑/宠物搭配，以及实时 2v2 竞技排位。

## 2. 主要竞品对比

| 维度 | 《神庙逃亡2》 (Temple Run 2) | 《地铁跑酷》 (Subway Surfers) | 《天天酷跑》 |
|---|---|---|---|
| **核心视角** | 3D 越野/悬崖视角（重力感应+划屏） | 3D 三轨道竖版跑酷（划屏） | 2D 横版卷轴跑酷 |
| **视觉风格** | 写实探险 / 奇幻神庙 / 主题王国 | 潮酷街头涂鸦 / 世界之旅 | 2D 卡通 Q 版 |
| **发行/运营** | Imangi / 创梦天地（乐逗） | SYBO / 创梦天地（乐逗） | 腾讯游戏 |
| **核心差异** | 具备悬崖转弯与重力感应倾斜；强调“角色+坐骑+宠物”技能组合；实时 2v2 竞技场 | 经典三轨道，强调滑板机制与城市文化旅程 | 腾讯社交关系链，重度数值与坐骑宠物体力消耗 |

## 3. 竞争优势与壁垒

1. **顶级 IP 认知度**：作为智能手机普及初期的标志性作品，《神庙逃亡》在广大中国移动用户中具备极高的品牌烙印。
2. **源码级本土化二次开发**：乐逗游戏拥有源码改编权，能够针对中国玩家偏好持续推出中国风神话/电影联动角色（如叶问、孙悟空、年兽）与排位竞技模式。
3. **创梦天地发行协同**：创梦天地同时代理《地铁跑酷》与《神庙逃亡2》，在交叉推广、流量互导与长线运营经验上具备独家赛道壁垒。
