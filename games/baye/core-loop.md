# 核心循环

## 领地攻占与国库分红循环

《霸业》的核心循环围绕城池争夺、官职进阶与税收分红展开：
- **城池攻占与通路连通**：城池是重要的资源出产地与国势衡量基础，主公通过攻占获得本国势力城池并连通通路，以占据更多城池与资源。
- **都城争夺与官职进阶**：都城是国战核心争夺目标，占领更多都城可促成全国官职晋升到更高品阶，并每天为国库提供更多收入。
- **税收结算与冬季分红**：元宝城能提供元宝税收，每季结算时根据本国占有的元宝城数目为国库提供元宝和银币税收；国库收入在每年冬季根据贡献分配给每位主公。[@来源](sources/core-loop.md#ev-da90729d016a4bcc7491ada357daed92)[@版本unknown] [@变更](.changelog/2026-10-13/change-b140608922eb4104aee7a63682ddf431.json) [@来源](sources/core-loop.md#ev-cd2ec566173c41638effe7adb2f2db8c)
