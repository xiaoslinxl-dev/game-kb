# 《寒霜启示录》基地建造系统：心愿驿站与娱乐设施运转规则

在《寒霜启示录》中，火晶时代的内城建筑升级、心愿驿站与娱乐设施运作规则如下：

## 1. 民意信箱改造与心愿驿站运作

- **心愿驿站与心愿解锁机制**：昔日的民意信箱改造为「心愿驿站」，用来承载幸存者们对未来生活的心愿；随着熔炉等级提升及前置心愿完成，将陆续解锁更多心愿 [证据](../sources/evidence.md#ev-18cd6b2f24e6f400da0aa53e010b9a33)。
- **心愿印记与建材兑换**：每次为幸存者完成心愿，领主可获得「心愿印记」，用于「心愿商店」中兑换后续娱乐建筑建造所需的专属材料 [证据](../sources/evidence.md#ev-18cd6b2f24e6f400da0aa53e010b9a33)。

## 2. 娱乐设施建造与每日产出加成

- **9座娱乐设施免费建造**：解锁火晶建筑后，城镇陆续推出9座全新娱乐设施；领主只要透过平日游戏活跃，无需额外门槛即可免费集齐全部建造材料 [证据](../sources/evidence.md#ev-ad4b9f25bff9ac767079cf972412cac5)。
- **每日道具随机产出与熔炉提升**：每座娱乐设施落成后，每日都将随机产出领主装备、领主宝石、宠物养成材料、专家培养材料、英雄装备等多项实用道具；提升火晶熔炉等级还可进一步提高每日道具产出量 [证据](../sources/evidence.md#ev-ad4b9f25bff9ac767079cf972412cac5)。
