# 《神庙逃亡2》核心循环：神庙逃亡与单局跑酷机制

在《神庙逃亡2》中，单局跑酷、背景设定与核心循环规则如下：

## 1. 游戏定位与研发发行

- **游戏类型与风格**：《神庙逃亡2》是一款3D建模写实风格的跑酷类休闲手游，属于角色扮演运动类冒险游戏 [证据](sources/evidence.md#ev-e6d1424392aae03c8f1239fbe25182c5)。
- **制作与代理发行**：游戏是由Imangi Studios、LLC制作，由乐逗游戏代理发行 [证据](sources/evidence.md#ev-e6d1424392aae03c8f1239fbe25182c5)。

## 2. 单局逃脱与无尽跑酷循环

- **核心目标与背景设定**：游戏背景设定在神庙里，玩家要逃脱恶魔守卫的追赶，穿越神庙夺取神像 [证据](sources/evidence.md#ev-e6d1424392aae03c8f1239fbe25182c5)。
- **无尽路线循环**：跑酷是一条怎么跑都跑不完的路程，玩家需要持续躲避障碍并坚持奔跑前行 [证据](sources/evidence.md#ev-e6d1424392aae03c8f1239fbe25182c5)。
