# 木筏地块扩展与人口突破机制初始规则

## 规则正文

1. **木筏网格扩展（rule-bb-expansion）**：开局引导解锁。消耗基础建材（木板、金属、塑料）沿边缘网格扩展木筏地块，地块最大占地规模受基地大本营（主城）等级严格限制。
2. **人口突破机制（rule-bb-pop-limit）**：当基地居民人口达到当前上限时，必须优先消耗建筑蓝图与轻质钢升级发电站、居民楼与医院等核心基础设施，突破人口容纳上限以解锁更多流水线与委派工位。
