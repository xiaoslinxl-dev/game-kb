# 核心循环

《神庙逃亡2》的核心游戏循环建立在“极简高频的操作体验”与“多元搭配的数值成长”之上。玩家通过单局跑酷获得金币、钻石及活动代币，再将资源投入到角色、坐骑、宠物与技能的升级与解锁中，进而挑战更高分数或在 PvP 竞技场中胜出。

## 核心循环图示

```text
[发起跑酷 / 竞技场匹配 / 主题地图探索]
                 │
                 ▼
     [单局避障操控与即时反应] ─── (拾取金币 / 能量罐 / 护盾 / 暴走道具)
                 │
                 ▼
     [单局结算与多维资源产出] ─── (金币、钻石、活动代币、段位赛季积分)
                 │
                 ▼
           [局外养成与解锁系统]
  ├── 角色 / 坐骑 / 宠物 技能强化与属性加成
  ├── 装备羽翼翅膀 / 佩戴限定称号与金币皮肤
  └── 黄金矿山挂机产出与幸运宝珠抽卡
                 │
                 ▼
           [追求更高目标]
  ├── 刷新无尽模式极限纪录与好友榜登顶
  ├── 冲击 1v1 / 2v2 排位赛王者段位与荣耀勋章
  └── 完成限时主题收集赛兑换限定奖励
```

## 核心步骤解析

1. **单局跑酷（Core Gameplay）**：
   - 玩家通过上下左右划屏手势与设备重力感应倾斜，操控角色在悬崖悬壁、滑索、矿车轨道及转弯路口避开树根、火焰、断崖等障碍，背后的恶魔守卫（追击猴子）紧随其后。
   - 跑酷途中拾取金币、能量罐与增益道具（磁铁、护盾、加速暴走、金币爆发）。详情参见 [单局跑酷与竞技对抗](/systems/session-combat.md)。
2. **三位一体技能联动**：
   - 能量槽充满后双击屏幕触发主角色专属技能（如冲刺暴走或生成护盾）。
   - 坐骑与宠物的被动/主动技能在特定条件下自动触发（如绊倒后概率生成护盾、加速距离延长、封印敌方技能等），形成深度的配队策略。
3. **结算与资源转化**：
   - 单局结算依据奔跑距离、金币收集量及综合得分倍率核算金币与账号经验。
   - 参与排位赛胜负产生段位星级与荣誉积分；限时主题版本产出专属收集道具（如芙蓉、雪花、西瓜、书本）。详情参见 [经济系统与代币循环](/economy.md)。
4. **长线养成与反馈**：
   - 消耗金币升级通用基础属性（如金币价值提升、磁铁时间延长、Save Me 复活折扣）。
   - 消耗钻石或宝珠解锁 S 级强力角色与神兽坐骑，大幅提高单局生存容错与排位对抗优势。详情参见 [进度与养成系统](/progression.md) 与 [商业化与变现设计](/monetization.md)。
