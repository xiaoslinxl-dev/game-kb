# 疯狂水世界 经济系统

《疯狂水世界》的经济系统围绕“原料打捞 - 工厂加工 - 订单变现 - 商店消费 - 战力转化”建立，兼顾了模拟经营的物资流转与卡牌 RPG 的深度数值消耗。

## 1. 代币与资源分类

| 资源/代币 | 主要产出途径 | 主要消耗用途 | 紧缺度/瓶颈阶段 |
|---|---|---|---|
| **金币** | 居民订单、贸易货轮、挂机收益、日常试炼、月卡每日赠送 | 英雄升级、装备打造、建筑建造与升级 | 全时期极度紧缺的第一基础货币 |
| **钻石** | 主线任务、关卡通关、活动成就、充值内购、往期活动道具（烧鸡）兑换 | 开服第 8 天转盘、特权商店买沙漏、租用自动生产 | 前期需严格囤积（1.5万钻保底），不可滥抽基础招募池 |
| **蓝图** | 70关以上关卡挂机掉落、日常任务、居民订单、联盟商店 | 所有高级建筑与工厂的建造和升级 | 前中期极度稀缺的建造红线物资 |
| **水母币** | 【联盟商船】订单交付与出海奖励（每日约 120-260 币） | 商船商店兑换黄金徽章自选、超凡藏品碎片、超凡技能书 | 联盟活跃度强相关的中后期高阶资源代币 |
| **竞猜积分** | 【巅峰擂台赛】全员赛事预测与对局竞猜（永久保留不清空） | 擂台赛商店兑换【登峰】核芯、洗刷锁、超凡万能碎片 | 顶级跨服竞技生态专属代币 |
| **洗刷锁** | 巅峰擂台赛商店、周活动、限时礼包 | 超凡装备与海兽洗炼时锁定核心词条（最多锁定 2 条） | 词条精炼防洗废的核心消耗道具 |
| **硅晶/硅矿** | S3 赛季大地图硅矿采集（每日限30次抢占）、周度加工活动 | 联盟科技研发、高阶装备精炼 | 中后期 SLG 联盟争霸核心战略资源 |
| **赛季币** | 赛季城战结算（盟主战利品分配）、赛季任务成就 | 赛季商店兑换红藏品“荣耀之巅”、海兽基因自选 | 长线跨赛季累积（结算不清空）硬通货 |

## 2. 生产与物资加工流转链

```text
  [海面打捞/拾荒船] ──► 木材、塑料、金属 ──► [材料厂/建材厂] ──► 墙纸、零件、钢板 ──┐
                                                                                 │
  [钓鱼台/海产捕捞] ──► 生鱼 ─────────────► [切鱼厂/海产厨房] ──► 生鱼片、罐头 ─────┼─► [居民订单 / 联盟商船 / 贸易货轮] ──► 金币 + 经验 + 沙漏 + 水母币
                                                                                 │
  [海水提取厂] ─────► 淡水、盐 ───────────► [日用品店/选种厂] ──► 饮用水、作物 ───────┘
```

1. **上游原料层**：海面拾荒、钓鱼台捕鱼、潜水船坞打捞深海物资、海水提取淡水。
2. **中游加工层**：切鱼厂、材料厂、选种厂、建材厂生产二级半成品与高级消耗品。
3. **下游变现层**：
   - **居民订单**：提交指定组合加工品，获取玩家经验与金币；S3 赛季起订单满意度奖励扩展至全传说英雄碎片。
   - **联盟商船**：联盟全员协作填补货舱订单，产出水母币。
   - **贸易港口货轮**：装载高阶成品换取大量金币、藏品宝箱与加速沙漏。
4. **资源回收与白嫖补充**：
   - 往期活动遗留道具（如“烧鸡”）可直接在背包内兑换为钻石，实现资产保值。
   - 漫剧演播厅每日观剧可稳定领取日常资源奖励。

## 3. 商店交易与代币流通

- **特权商店**：消耗钻石购买 1 分钟/5 分钟加速沙漏（首日微氪 V2 玩家通过购买 2400 沙漏刷货轮订单快速升至 16 级开启联盟）。
- **联盟商店**：消耗联盟贡献币兑换传说英雄碎片（如 [小丑杰克](/entities/units/xiao-chou-jie-ke.md)）、建造蓝图与海兽培育饲料。
- **商船商店**：消耗水母币兑换黄金徽章自选-随机S属性II、超凡藏品万能碎片、超凡技能书、史诗人鱼基因。
- **巅峰擂台赛商店**：消耗竞猜积分兑换【登峰】核芯、洗刷锁与超凡英雄万能碎片。
- **赛季商店**：消耗赛季币兑换红藏品“荣耀之巅”与超凡海兽升星数据自选。
- **战利品分配机制**：赛季结算最强联盟奖励调整为战利品形式，由盟主根据成员贡献与战功统一在联盟内部分配。
