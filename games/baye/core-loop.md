# 霸业 核心循环

《霸业》的玩法循环涵盖大地图国战、封地建设、日常政务与征战副本等多个层面的行动与资源连接。

## 大地图对抗与国库分红循环

在大地图对抗与领土扩张层面，游戏采用创新棋盘连城大地图，玩家参与全民攻城、突进封路、残兵撤退与密道突袭等实时战术布置，并通过行军加速秒到战场。[@来源](sources/core-loop.md#ev-e420e5e0337ab6b56372c492f28909cf)

在领土扩张的收益回馈层面，玩家通过攻城拔寨、扩张国家版图，并参与国家建设和国战，可免费瓜分海量元宝分红，形成国战对抗与核心元宝供给的正向循环。[@来源](sources/core-loop.md#ev-e420e5e0337ab6b56372c492f28909cf)

## 封地建设与巡城资源补充

在封地建筑升级与资源运转方面，每次建筑升级都需要一定的材料。根据攻略记载，前期若升级建筑次数较多，木头会十分缺少；在建筑升级的过程中，可以同步去攻城做巡城任务，每次巡城都会获得一定量的资源补充，以大地图巡城收益支持建筑升级。[@来源](sources/core-loop.md#ev-44c02d60ff846bf837a0d8850176ec1b)

## 日常政务、征战与副本养成推进

在日常政务、征战与副本养成环节，政务是至关重要的推进环节，每日政务次数需全部购买，以加速官邸升级、武将提升和血战沙场次数的增加。[@来源](sources/core-loop.md#ev-a9095836110f82bb7e77aa19ca4f770e)

此外，征战与副本系统构成武将与兵种成长的日常资源支柱：
- 每日征战中的血战沙场次数需购买满，以获取大量武将技能碎片和材料；[@来源](sources/core-loop.md#ev-a9095836110f82bb7e77aa19ca4f770e)
- 演义之路中的扫荡次数需尽量达到扫荡上限，以获取升级武将和兵种所需的材料、经验书和银币（升级武将技能需要消耗大量银币）。[@来源](sources/core-loop.md#ev-a9095836110f82bb7e77aa19ca4f770e)
