# Genshin Impact — Monetization

## Currency Architecture

Genshin Impact utilizes a multi-tiered currency system designed to obscure real-world monetary costs and maintain tight economic controls:

- **Genesis Crystals:** Paid currency acquired exclusively with real-world money. Converts 1:1 to Primogems.
- **Primogems:** Primary functional freemium currency used to purchase gacha wishes (160 Primogems = 1 Wish).
- **Intertwined Fate / Acquaint Fate:** Specific wish tokens for Event Banners and Standard/Beginner Banners.
- **Stardust & Starlight:** Secondary currencies refunded upon pulling gacha items, redeemable in Paimon's Bargains for wishes, ascension mats, and 4-star characters.

## The Gacha System (Wish Mechanics)

The core revenue driver is the character and weapon banner system.

### Character Event Wish
- **Base 5-Star Drop Rate:** 0.6%
- **Soft Pity:** Begins around pull 74, drastically increasing 5-star probability per wish.
- **Hard Pity:** Guaranteed 5-star unit at 90 pulls max (effectively ~75-80 pulls realistically).
- **The 50/50 Rule:** When pulling a 5-star item, there is a 50% chance it is the featured event 5-star, and a 50% chance it is a standard pool 5-star (e.g., Diluc, Jean, Mona). If a standard item drops, the next 5-star pulled is **100% guaranteed** to be the event character (persisting across banners).
- **Capturing Radiance System:** Introduced in version 5.0+, adding a mechanic to slightly improve 50/50 win probabilities for long-term players.

### Weapon Event Wish
- **Base 5-Star Drop Rate:** 0.7%
- **Fate Points System:** Players select a targeted 5-star weapon. If an unselected 5-star drops, a Fate Point is gained. At 1 Fate Point (updated from 2 in 5.0), the next 5-star pull is guaranteed to be the chosen weapon.

## Subscription & Battle Pass Sinks

1. **Blessing of the Welkin Moon ($4.99 USD / 30 days):**
   - Grants 300 Genesis Crystals upfront + 90 Primogems daily upon login (total 3,000 Primogems value; ~18.75 wishes). High value retention driver.
2. **Battle Pass (Gnostic Hymn $9.99 / Gnostic Chorus $19.99):**
   - 50-tier progression path yielding significant talent books, weapon EXP, Mora, Primogems, and exclusive 4-star weapons.
3. **Cosmetics & Outfits:**
   - Character skin cosmetics sold via Genesis Crystals (ranging from $15–$30 USD equivalent).
