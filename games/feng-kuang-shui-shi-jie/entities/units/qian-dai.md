# 千代 (Qian Dai)

## 1. 角色定位与特性

千代是《疯狂水世界》S2 赛季实装的超凡（Transcendent）品质刺客/输出英雄，其上线彻底打破了传统靠前排硬抗的 PVP 环境。

- **核心机制**：
  - **精准锁头**：优先以敌方攻击力最高的英雄（通常为敌方主 C [兰博](/entities/units/lan-bo.md)）为攻击目标。
  - **超强减伤与免控**：技能期间享受高达 60% 的伤害减免与控制免疫，规避 [机器屠夫](/entities/units/ji-qi-tu-fu.md) 的拉人与前排嘲讽。
  - **残血收割与隐匿**：击杀目标后进入短暂隐匿状态并刷新技能冷却，具备连环收割战局能力。

## 2. 装备与词条精练

- **词条优先级**：**暴击率** > **暴击伤害** > **攻击力百分比** > **抗性穿透**。
- **推荐装备**：
  - **兵刃**：破甲刃 / 离子光刃
  - **防具**：抗压头盔
  - **枪械**：榴弹发射器 / 脉冲步枪

## 3. 阵容搭配与对抗策略

- **克制目标**：极致克制以单核 [兰博](/entities/units/lan-bo.md) 为绝对输出的阵容。
- **反制手段**：防守方通常需要通过 [巫师老侃](/entities/units/wu-shi-lao-kan.md) 提供开局护盾保护，或者利用双刺客互切、前排高闪避阵容延缓其爆发节奏。
