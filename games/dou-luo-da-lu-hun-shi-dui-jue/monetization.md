# 商业化体系

《斗罗大陆：魂师对决》采用了成熟的数值卡牌商业化模式，通过“**卡池抽卡保底 + 限定诏令/通行证 + 分层礼包 + 皮肤与外观**”实现高 ARPPU 变现。

## 1. 抽卡卡池（Gacha）

- **常规与自选卡池**：提供 SSR 自选与日常武魂觉醒。
- **顶流卡池返场复刻（如「灵眸耀世复刻」）**：
  - 强攻系顶流 SP 魂师「神王·霍雨浩」限时召唤卡池复刻开启，支持情绪爆发/情绪崩坏机制与出离六道资源抽取，设置 60 抽幸运值与 400 抽大保底必得机制，累抽与星级达标可解锁定向源魂、专属魂骨与专属返场券。
- **SP / SP+ 限时主题卡池**：
  - 新魂师上线（如 `SP+ 太初食神·奥斯卡`、`SP+ 极致剑道·尘心`、`SP+ 十方琉璃·宁荣荣`、`SP+ 千面幻影·妖魅`）时开启专属卡池。
  - **保底机制**：通常设 50-60 抽保底或硬保底次数，首次或联动期间有保底抽数减免（如《仙逆》联动 SP 王林首次保底减少 50 抽）。
  - **源魂与神魂**：抽到本体后，后续需要继续抽取源魂/源心以解锁更高的神力阶级与技能分支。
- **长周期奇遇抽卡（如「金鳄之遇」）**：
  - 针对 SSR+ 梯队魂师，常采用为期 30 天的奇遇抽奖活动，通过日常活跃任务积攒代币（如【金鳄召集令】），支持自选心愿大幅提升抽中概率，平滑中小氪玩家与活跃平民的获取门槛。

## 2. 运营通行证与诏令（Pass System）

- **普通通行证 / 豪华通行证**：
  - **诏令系列**：如“金鳄镇渊”（2026年9月13日上线，全新防辅系 SSR+ 魂师金鳄斗罗首发专属诏令，解锁豪华版直接获取金鳄斗罗本体及信物）、“神念诏令”（2026年9月14日与「三炮对对碰」联动，产出天使圣谕与悬赏神念礼）、“神塔诏令”、“潮夏龙鸣诏令”、“光黯诏令”、“灵眸诏令”（2026年9月「灵眸凝视」配套）、“神赐诏令 / 神佑诏令”（2026年9月9日百级成神与非百级成神动态分流成长诏令）、“魂导诏令”（2026年9月11日上线，定向投放魂导器进阶礼Ⅰ/Ⅱ与魂导器自选礼）、“灵眸好礼”。
  - **微通行证机制**：通常为 7 天或 14 天周期，分为免费领取的「福利版」与付费解锁的「豪华版」（售价通常为 68元 - 128元 不等）。福利版可免费获取核心魂师碎片/信物、自选 SP 四肢魂髓或星源·魂环/月华秘图；豪华版额外解锁限定专属魂骨、定向源魂召谕、双神降临觉醒券、星源赐福礼、大量钻石及专属皮肤外观。

## 3. 礼包与订阅体系（Bundles & Subscription）

- **月卡与特权**：
  - **小月卡（30元）/ 大月卡（68元）**：购买立即获得钻石，31天内每日返还钻石与体力，并提供专属特权加速与副本资源产出加成。
  - **豪华月卡（全服月度订阅与签到双轨制）**：2026年9月期根据战区进度划分为「未开放百级成神战区」与「已开放百级成神战区」双轨体系。每日首次登录均可免费领取 30 点体力；累计签到天数达标可领取神息魂环甄选礼、海神碧玉、百万年自选始源、海神信物与举世名扬结晶礼；普通战区侧重于天枢涅槃石、自选核心/四肢魂髓及 SSR+ 魂灵自选，百级成神战区则定向输送高级铭值经验、月华秘图与魂纹元魄。
  - **堂主/VIP 特权**：充值累计达到对应档位（如 360 元）解锁多倍体力购买额度与托管快捷领取特权。
- **每日/每周分层礼包**：
  - 每日 1-18 元小额礼包（属性香肠、体力、觉醒券）。
  - 周常高阶礼包（燃骨灰烬、魂涡·锥、万能碎片）。

## 4. 特殊活动商业化

- **递进式三级转盘（「神界秘藏」）**：采用「宗门稀品 → 大陆珍宝 → 神界秘藏」三级转盘跳转机制。玩家消耗于秘藏商店购买的【寻宝罗盘】在活动转盘中抽取奖励；在宗门稀品与大陆珍宝抽中入口道具后跳转并返还1个罗盘；进入神界秘藏转盘后仅限单次抽取，抽中一次后因秘宝动荡落回宗门稀品；各转盘独立记录幸运值与特殊大奖保底，并配置累抽达标奖励（敏攻魂涡多代自选礼、SP魂灵自选礼、4星铠甲魂骨自选礼、超·赤羽焚天鸾、包罗万象肠等），神界秘藏奖池实装王道长·源心自选礼、妖魅不朽源骨自选礼（魇狐幻颅/绯雾噬心）、蜕变四肢骨自选礼等，形成极强的多层沉没与进阶付费驱动。
- **修罗应援 / 玉兔寻宝与神环好礼 / 神草幽梦 / 盛情夏日 / 祈福商城 / 斗魂奇石 / 赐福商城 / 星神限购 / 星月奇运 / 聚灵宝池（S23） / 游园寻宝 / 三炮对对碰 / 神赐好礼 / 竞技增益 2.0 特惠**：采用个人抽奖与全服应援进度里程碑联动（修罗应援投放修罗魔剑专属器源自选与杀心通明极意）、节庆全服捡福袋与高额神环返利联动（玉兔寻宝&神环好礼兑换李慕婉双系魂环与铠甲魂髓，最高500%~1000%返利）、“先抽后付”机制、双奖池幸运升档舍弃低层（盛情夏日）、幸运升档求签（星月奇运）、限时高战折扣直购（星神限购）、乐园棋盘掷骰（游园寻宝）、聚灵宝池共享海量钻石奖池大爆（S23）、高额返利（神赐好礼最高1000%返利，投放封号升阶信仰自选与举世扬名结晶）、58R竞技特权结晶礼包（竞技增益2.0）或三层星盘转盘抽奖机制，吸引中高氪玩家获取顶阶凶兽魂环、蜕变源骨、神骨至臻礼、简·幻金骨及 SSR+ 金鳄斗罗限定专属魂骨（踏渊吞岳/逆命擎天）等稀有资源。
