# 游戏概述

《神庙逃亡2》（Temple Run 2）是由美国知名游戏开发商 Imangi Studios 研发，并由深圳市创梦天地科技有限公司（乐逗游戏 / iDreamSky）在中国大陆引进、本地化二次开发与长线运营的 3D 越野跑酷动作手游。自 2013 年在中国正式上线以来，《神庙逃亡2》凭借极简顺畅的滑动与重力感应操控、紧张刺激的悬崖追逐体验，以及持续十余年的本土化深度改造，成长为中国移动游戏市场的国民级跑酷 IP 之一。

## 基本信息

- **游戏名称**：神庙逃亡2（英文名：Temple Run 2，常被民间玩家称为神庙逃跑2）
- **开发商**：Imangi Studios, LLC
- **中国发行与运营商**：深圳市创梦天地科技有限公司（乐逗游戏 / iDreamSky）
- **游戏版号/备案**：粤ICP备13029562号-44A / 新广出审[2016]789号（ISBN 978-7-89471-862-4，文网游进字〔2016〕0095号）
- **当前主流版本**：v7.3.2 (70302) / 客户端大小约 150MB~170MB
- **游戏类型**：3D 动作跑酷 / 休闲轻竞技
- **平台与网络**：iOS / Android / 微信小游戏；支持单机离线跑酷，并具备网络排位竞技场与在线主题运营活动。
- **官方社群与渠道**：官方网站（`tp2.uu.cc`）、官方微信公众号（`shenmiao2`）、官方 QQ 群（`904472600`）、官方微博（`神庙逃亡2手游`）、创梦天地 Fanbook 玩家社区。

## 本土化与演进历程

与海外原版纯粹的单机无尽跑酷不同，乐逗游戏获取了游戏源代码授权，针对中国本土玩家偏好进行了深度的二次开发与长线商业化改造：

1. **角色与外显多元化**：
   - 引入了大量中国风英雄与影视角色（如叶问、柳岩、孙悟空、赵云、小乔、穆桂英），以及动漫与节日主题角色（如安妮、比奥斯博士、万花仙子、沃利纳特）。
   - 深度开展跨界文化联动，例如携手敦煌画院推出以莫高窟“反弹琵琶伎乐天”为原型的文化角色 [雅丹天女](/entities/units/yadan-tian-nu.md) 及“丝路奇遇”赛道。
   - 建立了包含角色炫装、翅膀羽翼（如虎虎生威、花蝶梦）、个性化帽子及限定称号的外显系统。
2. **三位一体技能体系**：
   - 在原有角色技能的基础上，增加了**坐骑系统**（如年兽、美洲豹、傲狠、神兽白泽）与**宠物系统**（如仙灵鹤、小香猪、冰雪精灵、冰凤凰），形成“角色 + 坐骑 + 宠物 + 羽翼”的多元数值与技能组合。
3. **多人竞技与社交**：
   - 推出了竞技场/排位赛（含 1v1 单人匹配与 2v2 双人组队），将传统单机跑酷转变为具备技能互掷与负面干扰对抗的轻度竞技网游，并辅以赛季通行证“荣耀勋章”。
4. **休闲减负与长线留存**：
   - 引入“黄金矿山”挂机爆金币与宝珠机制，大幅降低玩家获取养成资源的刷局压力。
   - 设立 7 日签到免费送 A 级角色（如比奥斯博士）、主题收集兑换赛（如芙蓉、雪花、西瓜、书本收集）以及观看广告积攒积分兑换珍稀碎片的“广告积分商城”，构筑了长效用户留存闭环。
5. **持续的主题版本更新**：
   - 从早期的天空穹顶、冰封暗影、月夜穹顶，持续扩展出“玩具王国”（含玩具火车、巧克力瀑布与巨型姜饼人机关）、“丝路奇遇”、“百花戈壁”、“全民假日”与“赛博神庙”等多风格赛道，并推出排队蜡烛、环保沙滩、情人节等专属金币皮肤。
   - 持续对触控灵敏度算法进行底层优化，滑屏延迟降低约 40%，大幅提升了高配与中低端设备的微操避障手感。
