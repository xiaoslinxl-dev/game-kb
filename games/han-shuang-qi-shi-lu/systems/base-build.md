# 寒霜启示录 城镇营建与核心建筑系统

《寒霜启示录》的城镇营建围绕冰雪环境中的生存保障与资源生产展开。在冒险初期，玩家需重点接触并建造以下关键建筑：

## 1. 供暖、人口与基础建材

- **大熔炉**：城镇的中心，为整个区域供暖，也为幸存者提供安全保障。升级大熔炉的次数越多，可用空间就越大。
- **民居**：为幸存者提供住处。需要建造多个民居，建造的民居越多，城镇容纳的幸存者就越多。
- **伐木场**：可生产木材，而木材是建造更多建筑和升级现有建筑的必备资源。[@来源](../sources/evidence.md#ev-499ad88c4433b184b92875abd6f8a07b)

## 2. 矿产开采、产能升级与医疗保障

- **煤矿厂**：为城镇带来煤矿，用于建筑施工和升级产能。制作装备和升级煤矿厂可为城镇提供更多煤矿。
- **铁矿厂**：生产第三种主要资源铁矿。铁矿与木材和煤矿一样，是升级装备和建筑的必备资源。
- **医务室**：可以通过治愈疾病、疗伤等方式来让幸存者恢复健康。[@来源](../sources/evidence.md#ev-5b41fe18c160e4c16260b7d654d633fc)

## 3. 食物供给、狩猎与探险设施

- **厨房与就餐**：将为城镇烹饪生肉，同时也是幸存者在不干活时用餐的地方。
- **猎人之家**：厨房需要生肉来供给幸存者，猎人之家作为生肉来源，幸存者外出狩猎后会将猎物带回小屋存放。
- **探险者之家**：通往探险模式，在该模式中一辆马车载着幸存者努力击败敌人，为城镇招募更多人手。[@来源](../sources/evidence.md#ev-6b509ef563028d337225670839fd529f)
