# 《霸业》核心循环：三国阵营争霸与封地建设循环

## 1. 游戏定位与核心玩法

- **游戏定位**：《霸业》是一款三国阵营争霸策略手游，独创的古潮美术风格，搭载快节奏国战玩法，辅以深度武将养成策略，真实还原古代三国战争体验 [证据](sources/evidence.md#ev-9493ad31ed88bb3f1560c02e915b1b47)。

- **势力选择与封地建设**：游戏中，玩家需要选择魏蜀吴其中一方势力，建设封地，招募三国名将，不断提升实力 [证据](sources/evidence.md#ev-9493ad31ed88bb3f1560c02e915b1b47)。
