# Rule revision（topic: systems/base-build）

## 规则正文

1. **大熔炉中枢**：大熔炉为城建核心，等级决定其他所有建筑（民宅、兵营、科技所等）等级上限与兵种阶级上限（T1-T10）。
2. **供暖与过载**：熔炉提供基础供暖抵御严寒；在夜晚与暴风雪期间可开启过载升温，加速消耗煤炭以维持幸存者健康与满意度。
3. **幸存者生命线**：幸存者分配至各生产工位；温度过低生病需进入诊所治疗，生病或罢工直接导致资源停产。
